# Agent Harness (Local) — 2026-08-01

## Summary

The headline event this week is **MCP `2026-07-28` shipping final on schedule**, unchanged in shape from the May 21 RC: stateless-first transport, Roots/Sampling/Logging formally deprecated on a 12-month window, and Tier 1 SDKs (TypeScript, Python, Go, C#) tagged v2.0.0 the same day — with TypeScript splitting into `@modelcontextprotocol/client` and `@modelcontextprotocol/server`. Tasks moved out of the experimental core into the `io.modelcontextprotocol/tasks` extension. Harness ecosystem impact was immediate: **OpenCode** shipped six patch releases (v1.18.5 → v1.18.10) between Jul 24–30 whose changelogs are dominated by MCP compatibility — including v1.18.9's "restored compatibility with legacy MCP SDK clients" — and **Crush v0.87 (Jul 24)** added OAuth 2.1 for MCP HTTP servers plus the Claude Channels extension. **vLLM 0.26.0 (Jul 27)** brings Inkling day-0, DeepSeek-V4 routing perf, and an FP32 `lm_head`; **SGLang 0.5.16 (Jul 25)** adds DSpark speculative decoding (383.7 tok/s on DeepSeek-V4-Pro TP8 B300). **Ollama 0.32.3–0.32.4** landed (Jul 23/25) with GLM tool-call fixes and Laguna 2.1 support. Open-question follow-ups: OpenHarness remains stalled (no tag since v0.1.9 on May 7); llama.cpp still has no native C++ MCP client (discussion #22640 quiet since May 6); Qwen 3.8-Max weights are still preview-only.

## MCP for local stacks (delta since 2026-07-25)

- **MCP `2026-07-28` shipped final on schedule.** Announcement blog: <https://blog.modelcontextprotocol.io/posts/2026-07-28/>.
  - **Delta vs the May 21 RC**: The RC's shape held — stateless-first, no `Mcp-Session-Id`, no `initialize` handshake, header-based routing, cacheable list results, RFC 9207 issuer validation, formal deprecation policy. What changed by ship:
    - **Tier 1 SDKs finalized at v2.0.0** (TypeScript, Python, Go, C#); Rust in beta.
    - TypeScript now ships as **two packages**: `@modelcontextprotocol/client` and `@modelcontextprotocol/server` (breaking import change).
    - **Tasks moved out of the experimental core** into the `io.modelcontextprotocol/tasks` extension (poll-based ops + change notifications).
    - **Roots, Sampling, Logging** formally deprecated with ≥12-month offramp.
    - **Dynamic Client Registration** shifting toward Client ID Metadata Documents (CIMD).
    - **Legacy HTTP+SSE transport** deprecated with a one-year window.
    - Extensions framework named entries: MCP Apps (server-rendered iframes), Tasks, Enterprise Managed Auth.
- **Downstream impact already visible in this week's harness releases**:
  - **OpenCode v1.18.8** (Jul 28) — "Improved compatibility with newer MCP servers and OAuth flows"; **v1.18.9** (same day) had to restore compatibility with legacy MCP SDK clients — a live example of the SDK v2 break biting.
  - **Crush v0.87** (Jul 24) — MCP OAuth 2.1 + Claude Channels extension.
  - **Codex CLI** (Jul 28) — MCP + Apps tool refresh, transient-disconnect resilience for stdio MCP.
- **llama.cpp** — native C++ MCP client still not merged; discussion #22640 quiet since May 6.
- **Ollama** — no first-party MCP client this week; community `mcp-client-for-ollama` still the path.
- **SGLang / vLLM / TensorRT-LLM** — no MCP integration on the server side this week.
