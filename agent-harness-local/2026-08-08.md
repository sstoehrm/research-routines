# Agent Harness (Local) — 2026-08-08

## Summary

The two weeks since 2026-07-25 were the **MCP 2026-07-28 GA** cycle. The
spec landed on schedule with the biggest surface changes it has ever
shipped: stateless-first core (no `initialize` handshake, no
`Mcp-Session-Id`), Multi Round-Trip Requests replacing server-initiated
streams for input prompts, header-based routing, cacheable list results,
and RFC 9207 hardening on OAuth 2.1. Deprecates Roots, Sampling, and
Logging (12-month minimum support). All beta SDKs (TypeScript v2 ESM-only,
Python v2 with the `FastMCP → MCPServer` rename, Go v1.7.0-pre.1,
C# 2.0.0-preview.1, Rust beta) went stable on the same day. Harnesses
followed within a week: **OpenCode 1.18.8** shipped MCP 2026-07-28 support
same-day, **Codex CLI rust-v0.147.0** picked up the spec on Aug 7 alongside
its new portable Agent Plugins system, **Crush** released 0.87 → 0.88.1
adding OAuth 2.1 for HTTP MCP servers, MCP channels for server
notifications, LSP rename/replace-symbol tools, and a new `.crushrc`
bash-based config format. **Nous Hermes Agent v0.20.0 "Herald"** launched
Aug 3 with streaming voice + barge-in, native desktop app, `!command`
shell mode, and A2A v1.0 agent-to-agent protocol. Backends were quieter:
**Ollama 0.32.4 → 0.32.6** improved MLX perf on Apple Silicon (~4–9% on
M5 Max, MTP-head auto-use for speculative decoding) and aligned the
`/v1/chat/completions` streaming wire format with OpenAI more strictly;
**SGLang v0.5.17 (2026-08-08)** added a Rust ingress frontend and
session-reference-aware KV eviction for agentic workloads; **llama.cpp**
had ten builds on 2026-08-07 alone but none touched tool-calling or MCP.
**vLLM** did not ship a verified release in-window. On model+harness
combos, no new SEO-viral "hero pairing" surfaced with a verifiable primary
source — this cycle's honest update is *"the July combos still work;
here is what changed in the plumbing under them."*

## MCP 2026-07-28 — landed on schedule

- Primary: <https://blog.modelcontextprotocol.io/posts/2026-07-28/> (GA)
- SDK betas / RC: <https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/>
- License: MIT (spec repo)

Surface changes that matter for local harnesses:

- **Stateless protocol core** — removes `initialize` / `initialized`
  handshake and `Mcp-Session-Id`. Local MCP servers can sit behind plain
  round-robin load balancers; `tools/list` can be cached.
- **Multi Round-Trip Requests (MRTR)** — replaces server-initiated streams
  for confirmations / missing parameters. Server returns
  `resultType: "input_required"`; client retries with the answers attached.
  Removes the last remaining reason a purely local MCP client had to
  maintain long-lived server-initiated streams.
- **Header-based routing** — new `Mcp-Method` / `Mcp-Name` headers let
  gateways route without parsing JSON bodies.
- **Cacheable list results** — `tools/list`, `prompts/list`,
  `resources/list` now carry `ttlMs` and `cacheScope`.
- **Authorization hardening** — RFC 9207 issuer validation required;
  Dynamic Client Registration deprecated in favor of Client ID Metadata
  Documents.
- **Extensions framework** — reverse-DNS identifiers, dedicated `ext-*`
  repos, versioning independent of core. Tasks moved to the
  `io.modelcontextprotocol/tasks` extension. Roots, Sampling, Logging are
  deprecated (12-month minimum support).
- **MCP Apps** — server-rendered interactive HTML in sandboxed iframes,
  declared as UI templates on tool definitions.
- **Formal deprecation policy** — 12-month floor before removal.

SDKs on the GA date: TypeScript v2 (ESM-only, split into
`@modelcontextprotocol/server`, `@modelcontextprotocol/client`), Python v2
(FastMCP → MCPServer rename, decorator API preserved), Go v1.7.0-pre.1,
C# 2.0.0-preview.1, Rust in beta.

Backward compatibility: 2026-07-28 clients fall back to the legacy
handshake against servers on 2025-11-25 or earlier; existing servers keep
working. In practice this means an air-gapped local stack can upgrade the
harness first and the servers on its own schedule.

Verified harness support so far:

- **OpenCode 1.18.8** — same-day (2026-07-28).
- **Codex CLI rust-v0.147.0** — 2026-08-07.
- **Crush 0.87 → 0.88.x** — OAuth 2.1 + MCP channel extensions.
- **OpenHands v1.10.0** — MCP credential preservation during mutations.
