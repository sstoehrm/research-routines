# Agent Harness (Local) — 2026-09-05

## Summary

Late-July through early-September 2026 was the "Kimi K3 + Muse
Glimmer" window: two major open-weight model launches (Kimi K3 on
2026-07-27 with 2.8T total / 104B active, Muse Glimmer on 2026-08-10
with 30B under Apache-2.0) plus DeepSeek V4-Flash-0731, GLM-5.3
(2026-08-14, open weights 2026-08-28), Qwen 3.8-Flash-Next
(2026-08-26), and NVIDIA Nemotron 3.5 Lightning (2026-08-11) turned
each backend cycle into a day-0 sprint. **vLLM 0.27 (2026-08-10)** and
**0.28 (2026-08-26)**, **SGLang 0.5.17 (2026-08-08)** and **0.5.18
(2026-08-22)** all shipped day-0 parsers for these models plus real
concurrency wins (SGLang TP-LMHead 320µs → 169µs on B200; startup
2.38× faster on H100). **Ollama** cadence was frantic — nine tagged
releases in the window, culminating in **v0.33.0 (2026-08-21)**
that promotes Claude Desktop to a third-party gateway provider and
**v0.33.1–0.33.3** that closed the MLX gap for Qwen 3.8-Flash-Next.
**llama.cpp b10217 (2026-08-01)** patched the DS4 "tool-call inside
`<think>`" parser, and the 0.4.0 tag (2026-09-04) brought day-0
Qwen 3.8-Flash-Next / Nemotron-3-Puzzle plus Apple Thunderbolt-RDMA
transport. On harnesses, **Hermes Agent** shipped two more mega
releases ("Herald" v0.20.0 on 2026-08-03 and "Pantheon" v0.21.0 on
2026-08-31), **Crush** made steady MCP/OAuth progress across nine
tags, and **Codex CLI v0.149.1 (2026-08-24)** deprecated the old
`codex mcp-server` subcommand in favour of an App Server / plugin
model with a new async `mcp_tool` hook handler. No new MCP spec
revision landed; **2026-07-28** remains the current wire.
