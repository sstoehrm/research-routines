# Agent Harness (Local) — 2026-06-27

## Summary

The May–June 2026 window was busy on every layer of the local-agent
stack. **Tool-call parsing in llama.cpp** got hardened across at least
nine PRs (LFM2 / LFM2.5 unification, peg-native wrapping for OpenAI-
style `{"type":"function",...}` payloads, jinja `call` for MiniPCM4-MCP)
and **Ollama** completed its switch to upstream `llama-server` as the
sole GGML runner in v0.30, then turned `ollama launch` into a launcher
for `opencode`, `omp`, `hermes-desktop`, and `qwen-code`. **SGLang
v0.5.12** shipped a real Tool-Call / Reasoning parser stack with
auto-detection from chat templates; **LocalAI 4.5** fixed structured-
output regressions on vLLM ≥ 0.23. On the harness side: **Goose** went
weekly with Vulkan / CUDA / MLX local-inference paths and a dynamic
Ollama Cloud provider; **OpenCode** added session-snapshot revert and
heavy MCP work; **Hermes Agent** shipped a desktop app and an
**OpenAI-compatible local proxy** that turns any of its OAuth providers
into a local endpoint Codex / Aider / Cline / Continue can hit;
**OpenHarness** matured its MCP isolation; **OpenHands** split its
agent core into a `software-agent-sdk` + `agent-canvas` UI. Two
notable shutdowns: **Plandex** has had zero commits to `main` in the
window (cloud wind-down notice landed late 2025), and **Roo Code** was
archived on 2026-05-15, with **Zoo Code** taking over as the community-
led successor (3.64.0, June 26). **Aider** has not cut a release since
v0.86.0 (2025-08-09); `main` only has model-keyword housekeeping.
