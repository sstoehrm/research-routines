# Agent Harness (Local) — 2026-08-15

## Summary

The three-week window since 2026-07-25 was dominated by three things:
the **MCP `2026-07-28` spec** shipping on schedule as the largest
revision since launch (stateless core, MRTR, header routing, Tasks and
Apps as formal extensions, OAuth 2.1 with RFC 9207 + CIMD), a wave of
new open-weight models (**Kimi K3** on 2026-07-27, **Qwen 3.8-Max** on
2026-08-03 with open weights 2026-08-12, **Meta Muse Glimmer** on
2026-08-10, **NVIDIA Nemotron 3.5 Lightning** on 2026-08-11,
**Qwen 3.8-27B** on 2026-08-14, **DeepSeek V4-Pro-0813 GA** in
mid-August, **GLM-5.3** on 2026-08-14), and a serving-side reshuffle
where both **vLLM v0.26.0** (2026-07-27) and **SGLang v0.5.17**
(2026-08-08) picked up day-0 support for the ones that shipped weights.
Kimi K3 remains **unmerged in llama.cpp** (PR #26185); MiniMax MSA is
still only in a WIP fork. On the harness side, **Hermes Agent** cut
**v0.20.0 "Herald"** (voice + A2A v1.0), **Crush** landed
**MCP OAuth 2.1** for HTTP MCP servers, **Codex CLI** picked up
MCP 2026-07-28 + `--approve-for-me`, **OpenHarness is still
stalled** at v0.1.9 (2026-05-07), and **Continue.dev's Cursor
acquisition** is now traceable to primary sources (announced
2026-06-18; cloud data deleted after 2026-07-15). For a
"just runs on a 24 GB card" agent slot the standout new pick is
**Muse Glimmer 30B (Apache-2.0) + Ollama / LM Studio**; for
"largest thing you can serve" it's **Kimi K3 MXFP4 + SGLang v0.5.17
on GB300**.

## MCP for local stacks

- **MCP `2026-07-28` shipped final on 2026-07-28.** Largest
  revision since launch, replacing 2025-11-25. Stateless-first
  core: `initialize`/`initialized` handshake and `Mcp-Session-Id`
  header are gone; each request carries protocol version, client
  identity, and capabilities in `_meta`. **`Mcp-Method` /
  `Mcp-Name` headers** enable gateway/WAF routing without
  parsing JSON bodies. **Multi Round-Trip Requests (MRTR)**
  replaces server-initiated bidirectional streams — servers now
  return `resultType: "input_required"` and clients retry with
  the needed inputs attached. **Cacheable list responses**
  (`ttlMs`, `cacheScope`) for tools/prompts/resources. OAuth
  hardened: RFC 9207 issuer validation, shift from Dynamic Client
  Registration toward **Client ID Metadata Documents (CIMD)**.
  Roots / Sampling / Logging **deprecated** with 12-month
  minimum window; legacy HTTP+SSE transport deprecated with same
  timeline. All four Tier 1 SDKs (TS, Python, Go, C#) speak it on
  day one; Rust follows in beta.
  Blog: <https://blog.modelcontextprotocol.io/posts/2026-07-28/>
- **Tasks and Apps are formal extensions**, not core. `Tasks`
  moved from experimental core into
  `io.modelcontextprotocol/tasks` (SEP-2663) with poll-based
  `tasks/get` replacing blocking `tasks/result`. **MCP Apps**
  (SEP-1865) is now official: servers ship interactive HTML
  interfaces that hosts render in a sandboxed iframe; UI
  templates are declared ahead of time for prefetch and security
  review; all UI-initiated actions traverse the same JSON-RPC
  consent path as tool calls.
- **Crush** shipped MCP OAuth 2.1 for HTTP MCP servers in v0.87.0.
- **OpenCode** restored legacy MCP SDK compat and fixed SSE
  reconnection during the window.
- **Codex CLI v0.147.0+** speaks MCP `2026-07-28`.
- **Ollama, vLLM, SGLang, llama.cpp, TensorRT-LLM** — still no
  first-party MCP client; integration remains harness-side.
- **LM Studio** — added stateful `/v1/chat` REST endpoint for
  local MCP tool use; remains the most complete GUI MCP host.
- **Jan** — no new MCP surface in the window (v0.8.4 stands).
