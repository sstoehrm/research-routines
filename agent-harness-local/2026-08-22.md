# Agent Harness (Local) — 2026-08-22

## Summary

Late July through August 2026 was dominated by four things.

1. **The MCP `2026-07-28` spec shipped on schedule** — all four Tier-1
   SDKs (TypeScript, Python, Go, C#) are aligned at launch day. Extensions
   Framework formalized; MCP Apps, Tasks, and Enterprise Managed
   Authorization (EMA) are now official extensions rather than
   experimental.
2. **A wave of open-weight releases pointed squarely at local agents.**
   Moonshot's **Kimi K3** (2.8T MoE, July 26–27) landed with day-0
   vLLM and SGLang support. Meta open-sourced **Muse Glimmer 30B**
   under Apache 2.0 on Aug 10, and Zuckerberg publicly committed to
   opening **Muse Spark 1.2** weights. NVIDIA shipped **Nemotron 3.5
   Lightning** (30B MoE, 3B active) on Aug 11, explicitly positioned
   as the always-on-agent execution model. Alibaba shipped
   **Qwen3.8-Max** (2.4T/95B) weights on Aug 12 and **Qwen3.8-27B**
   (Apache 2.0, native VL, 262k ctx) on Aug 14. Z.ai released
   **GLM-5.3** on Aug 14 (same base as GLM-5.2 with agent-focused
   post-training). DeepSeek promoted **V4-Pro-0813** to GA on Aug 13.
3. **A brand-new agent-harness category is emerging.** **DeepSeek
   Harness** (`dsh`) shipped in developer preview on Aug 13 under MIT
   with an "everything is a plugin" architecture (built on Cordis v4);
   it reportedly hit ~95k GitHub stars in two days. Meta's **Muse
   Code** (Aug 5, closed for now) is a Claude-Code-shaped terminal
   agent that ships with the Muse Spark 1.2 model.
4. **Hermes Agent shipped its largest single release ever.** v0.20.0
   "The Herald Release" (Aug 3) added streaming voice TTS with
   barge-in, A2A v1.0 protocol, signed webhooks, and grounded
   research with citations — ~3,650 commits since v0.19.0.

Backends kept executing the same play: **vLLM 0.27.0** (Aug 10) landed
Kimi K3 support, Qwen3.5 MoE, DeepSeek-V4 optimizations, and Model
Runner V2 for non-generative workloads; **SGLang v0.5.17** (Aug 8)
added day-0 Kimi K3 and MiniMax-H3 (video-with-audio). **Ollama**
executed a near-daily patch train through v0.32.15, integrating Muse
Glimmer, Nemotron 3.5 Lightning, Muse Code, DeepSeek Harness, and
Qwen 3.8 27B, and pre-released **v0.33.0** with Claude Desktop
integration on Aug 21. **KTransformers 0.7** (Aug 17) expanded
AVX-512 support to LoRA fine-tuning without AMX, benefiting AMD EPYC.
**llama.cpp** continues its build-tag cadence (b10524 as of Aug 20)
with reasoning-effort passthrough and Nemotron MTP.

### DeepSeek Harness (deepseek-ai) — NEW

- Source: <https://github.com/deepseek-ai/deepseek-harness>
  (via <https://deepseek.com/harness/>)
- License: MIT (developer preview, 0.1.0-rc.5)
- What it is: New open-source terminal coding agent launched
  **2026-08-13** alongside DeepSeek V4-Pro-0813 GA. Organizing idea:
  "everything is a plugin" — models, tools, skills, sessions,
  sandboxes, filesystems, loops, orchestration, and UI are all

  API but the harness itself does not require it.

  search files and the web, maintain plans, invoke skills, delegate
  to subagents, enforce approval policies.
- Adoption note: reported ~95,386 stars / 8,826 forks within
  ~48 hours of publication per InfoQ / Flowtivity — one of the
  fastest adoption curves on record; treat exact numbers as
  secondary until verified against the repo's actual counter.

## MCP for local stacks

- **MCP `2026-07-28` FINAL shipped on schedule.** Stateless-first
  core; `initialize` / `initialized` handshake and
  `Mcp-Session-Id` header removed; each request self-describes via
  `_meta`. **Header-based routing** on `Mcp-Method` and `Mcp-Name`
  lets gateways route without JSON parsing. **Multi Round-Trip
  Requests (MRTR)** replace server-initiated requests that needed
  open streams (mid-call user confirmations now work statelessly).
  **Cacheable list results** carry `ttlMs` and `cacheScope`.
  Auth: RFC 9207 issuer validation, DCR deprecated in favor of
  **CIMD (Client ID Metadata Documents)**, client credentials
  bound to issuer. **Extensions Framework** formalized; **Tasks**,
  **MCP Apps** (sandboxed-iframe UIs served by the tool), and
  **Enterprise Managed Authorization (EMA)** are official
  extensions. Roots, Sampling, and Logging deprecated with a
  12-month minimum transition window; legacy HTTP+SSE transport
  deprecated. **All four Tier-1 SDKs (TypeScript, Python, Go, C#)
  are aligned at launch.** TypeScript v2 retires the monolithic
  `@modelcontextprotocol/sdk` in favor of focused packages
  (`@modelcontextprotocol/server`, `@modelcontextprotocol/client`).
  Rust SDK is beta.
  Blog: <https://blog.modelcontextprotocol.io/posts/2026-07-28/>
  Spec: <https://modelcontextprotocol.io/specification/2026-07-28>
  SDK betas: <https://blog.modelcontextprotocol.io/posts/sdk-betas-2026-07-28/>
  Google Cloud framing:
  <https://developers.googleblog.com/scaling-ai-agent-infrastructure-with-the-mcp-stateless-updates/>
  Coverage: <https://www.theregister.com/devops/2026/07/23/model-context-protocol-prepares-to-break-with-its-stateful-past/5276722>,
  <https://realpython.com/python-news-august-2026/>
- **llama.cpp** — MCP still lives in the web UI, not in the C++
  server. Social claims of "native stdio MCP" landing in
  llama-server are unverified against a primary PR here.
- **Ollama** — still no first-party MCP client; community bridge
  `mcp-client-for-ollama` (ollmcp) remains the path.
- **LM Studio** — Host + OAuth + new stateful `/v1/chat` endpoint
  for MCP; still the most complete GUI MCP surface.
- **Jan** — no window changes past v0.8.4 inline MCP tool approval
  and native web_search / web_fetch.
- **SGLang, vLLM, TensorRT-LLM** — MCP remains client-side through
  harnesses.
