# Agent Harness (Local) — 2026-09-12

## Summary

The Jul-25 → Sep-12 window was dominated by **Kimi K3** (Moonshot AI, ~2.8T
MoE / 16 of 896 experts active, 1M ctx, released 2026-07-27), which
shipped with same-day recipes on **vLLM** and **SGLang** — the fastest
day-0 turnaround for a trillion-scale open model to date. **SGLang** put
out three fast-cadence releases (v0.5.17 → v0.5.19) that migrated the
front half of the server to Rust, cut Qwen3-32B cold start from ~85 s
to ~36 s, and stabilised tool-call streaming for DeepSeek V4 and Kimi
K3. **vLLM v0.27.0 / v0.28.0** landed Model Runner V2 maturation,
DeepSeek V4 sparse-MLA decode, and a unified Mistral parser. On models,
**DeepSeek V4-Flash-0731** and **V4-Pro-0813** refreshed the V4 line,
**Alibaba** shipped **Qwen3.8-Max** (Aug 3) and **Qwen3.8-Flash-Next**
(Aug 26, ~125 B/6 B active, MIT-adjacent "Qwen Community 1.0" license),
and **NVIDIA** shipped **Nemotron 3.5 Lightning** (~30 B MoE). The
**MCP `2026-07-28` spec** shipped on schedule; MCP maintainers posted an
updated roadmap on 2026-08-22. **Ollama v0.33** wired in first-class
**Claude Desktop** integration; **v0.34.0** added ChatGPT Desktop, and
the **MLX runner** finally gained structured output. **Hermes Agent**
kept its heavy release cadence with a "Herald" (Aug 3) and "Pantheon"
(Aug 31) drop that landed Bot Mode + A2A v1.0. **KTransformers v0.7.0**
(Aug 17) added AVX-512 LoRA and native FP8 fine-tuning for very large
MoE. **llama.cpp** continued nightly builds through b10917 (Sep 11) but
still ships no in-server native MCP client — the March 2026 merge was
UI-level only.

- **v0.27.0 (2026-08-10)** — 561 commits from 242 contributors.

  grammar-constrained decoding works across the reasoning boundary with

  MTP + DSpark; Model Runner V2 maturation with E/P/D disaggregation
  and weight offloading; tiered KV-cache offloading with disk support;

  `calculate_kv_scales` removed. Details:
  <https://github.com/vllm-project/vllm/releases/tag/v0.28.0>
