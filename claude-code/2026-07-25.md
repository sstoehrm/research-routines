# Claude Code — 2026-07-25

## Summary

The May–July 2026 cycle for Claude Code was defined by (1) two new
Anthropic-official security plugins — **security-guidance** (2026-05-27)
for per-edit / end-of-turn / pre-commit review and **claude-security**
(2026-07-22) for on-demand multi-agent vulnerability scans; (2) a large
infrastructure refactor around plugins and skills — `.claude/skills`
auto-loads without a marketplace, `/reload-skills` and
`SessionStart → reloadSkills: true` bring changes in mid-session, skills
and commands can declare `disallowed-tools`, and stacked
`/skill-a /skill-b` invocations load all leading skills up to five;
(3) **dynamic workflows** (v2.1.154, 2026-05-28) as a research preview,
now the foundation for `claude-security`; and (4) a `/dataviz` bundled
skill (v2.1.198, 2026-07-01). The bundled `/simplify` skill was renamed
to `/code-review` with no alias — quiet-break for teams that scripted
against the old name. Superpowers crossed **~941K installs**; Caveman
roughly doubled its GitHub stars; **Record a Skill** (Cowork, 2026-07-21)
introduces a screen-record-to-SKILL.md authoring pipeline that will feed
the wider ecosystem. Two adjacent security items shape the context:
Mozilla 0DIN's PoC of indirect prompt injection via a clean-looking
repo (June) and disclosure of a hidden telemetry marker in Claude Code
(July) that Anthropic called an "experiment." A shell-injection fix in
v2.1.214 (2026-07-18) tightened plugin option handling.

## Plugins

### security-guidance (Anthropic-official, NEW)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/security-guidance>
- Docs: <https://code.claude.com/docs/en/security-guidance>
- Install: `/plugin install security-guidance@claude-plugins-official`
- License: Anthropic (per the official marketplace repo)
- Announced: 2026-05-27 (Help Net Security; What's-New Week 22)
- Requires: Claude Code v2.1.144+, Python 3.7+ (3.10+ for agentic
  commit review); needs a git repo.

Three-layer in-session security review:

1. Per-edit deterministic pattern match on `Edit / Write /
   NotebookEdit`.
2. End-of-turn LLM diff review via a `Stop` hook (default Opus 4.7).
3. Agentic commit / push review on `PostToolUse:Bash` filtered to
   `git commit` / `git push`, using a Claude Agent SDK subprocess.

Findings are fed back to Claude as follow-up context in the same
session. Anthropic reports a 30–40% reduction in security-related PR
comments internally.

Notes / caveats worth flagging:

- Uses `SessionStart`, `UserPromptSubmit`, `PostToolUse`, and `Stop`
  hooks — a hook-heavy plugin.
- Creates a venv under `~/.claude/security/` and pip-installs the
  Agent SDK on first run (network + write access).
- Model-backed reviews cost usage; commit review capped at 20/hour.
- Extends via `.claude/claude-security-guidance.md` and
  `.claude/security-patterns.yaml`, both checked in by default.
- Enabling for cloud sessions or shared repos writes to `.claude/
  settings.json` `enabledPlugins` — modifies checked-in settings.
- Reads env vars `SECURITY_REVIEW_MODEL`, `SG_AGENTIC_MODEL`, and
  `SECURITY_GUIDANCE_DISABLE`.
- In the Anthropic-managed marketplace.

### claude-security (Anthropic-official, NEW)

- Docs: <https://code.claude.com/docs/en/claude-security>
- Install: `/plugin install claude-security@claude-plugins-official`
- License: Anthropic
- Announced: 2026-07-22 (public beta) — MarkTechPost,
  cybersecuritynews.com, Wes Roth on X
- Requires: Claude Code v2.1.154+, Python 3.9.6+ (stdlib only, no
  pip install), paid plan, `gh` signed in for open-PR discovery.

On-demand multi-agent vulnerability scan of a whole repo or a diff
(branch / PR / single commit), driven by dynamic workflows. Distinct
from **security-guidance** (that one is per-edit; this one is deep-scan
on demand) and distinct from the managed **Claude Security**
enterprise product (which monitors repos remotely).

Adds one command: `/claude-security`, with menu options "Scan
codebase", "Scan changes", "Suggest patches". Writes results to a
timestamped `CLAUDE-SECURITY-<timestamp>/` directory (with its own
`.gitignore`); patches land in `patches/` as `F<n>.patch` and are
**never auto-applied**.

Notes / caveats:

- Beta / public research preview.
- Uses dynamic workflows — scans may use significant tokens; Anthropic
  warns explicitly.
- Runs best in auto mode; the plugin prompts about this at job start.
- Only committed changes are scanned.
- In the Anthropic-managed marketplace.

## Skills

### /dataviz (Anthropic-bundled, NEW)

- Source: in-repo bundled-skills tree of `anthropics/claude-code`
- Added: 2026-07-01 in **v2.1.198**
- Docs: <https://code.claude.com/docs/en/skills>

Chart and dashboard design guidance loaded on demand — chart-type
selection, color-by-role, layout rules, plus a runnable color-palette
validator. Followed up 2026-07-24 (v2.1.219) with a reordered default
palette and fixed guidance for four-series charts.

Behavior: bundled, so on by default. Can be turned off with the
`disableBundledSkills` setting or `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS`
env var (both added in Week 24, v2.1.166–176).

### /code-review (Anthropic-bundled, RENAMED)

- Change: in **v2.1.146** the bundled `/simplify` skill was renamed
  to `/code-review`. **No alias** — old name breaks. Adds optional
  effort levels (`/code-review high`, etc.).
- `/review <pr>` now calls the same engine as `/code-review medium`
  (v2.1.185–193).
- Community rescue plugin `gtapps/simplify` restores the old command.

Impact: any project skill also named `code-review` will shadow the
bundled one — worth flagging as a naming-collision risk for teams.

### Claude-API skill retargeted to Opus 5

- Change (v2.1.219, 2026-07-24): the bundled `claude-api` skill now
  defaults to **Claude Opus 5** with a migration path documented
  from Opus 4.8.

### Record a Skill (Cowork, NEW authoring surface)

- Announced: 2026-07-21 (Explainx.ai, cybersecuritynews.com,
  TheDecoder)
- Availability: Cowork feature in Claude Desktop's `+` menu — **not**
  in the CLI itself.

Screen-record a workflow with voice-over; Claude analyzes and
generates the corresponding `SKILL.md`, which lands in the user's
skill library and can be re-invoked. Because the output is a plain
`SKILL.md`, produced skills are portable to Claude Code and any
other SKILL.md-compatible harness (Codex, Cursor, Gemini CLI).

Plans: Pro, Max, and Team.

Notes: worth watching because this is a new authoring pipeline that
will feed the wider Claude Code skill ecosystem without going through
a marketplace review step.
