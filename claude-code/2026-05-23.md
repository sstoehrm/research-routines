# Claude Code — 2026-05-23

## Summary

Claude Code shipped 31 versions (2.1.119 → 2.1.149) between
2026-04-23 and 2026-05-23. The window's themes: **(1) plugin
hygiene** — `/plugin` Browse/Discover now shows projected context
cost (2.1.143), last-updated date (2.1.144), and a complete
"Will install" pane listing commands, agents, skills, hooks, MCP and
LSP servers before install (2.1.145); plus plugin dependency
enforcement and a `claude plugin prune` for orphans; **(2) skill
loading** — `skillOverrides` now actually works (off / name-only /
user-invocable-only), `/skills` got type-to-filter, per-skill token
estimates use the model's tokenizer, and the built-in `/simplify`
was renamed to **/code-review** with effort levels and `--comment`
for inline GitHub PR comments (2.1.147); **(3) MCP correctness** —
paginated `tools/list` no longer silently drops tools (2.1.147),
`MCP_TOOL_TIMEOUT` lets remote HTTP/SSE servers run longer, and
`CLAUDE_PROJECT_DIR` is exposed to stdio MCP servers (2.1.139).
Notable plugin/skill activity: **alirezarezvani/claude-skills v2.8.2**
shipped on **2026-05-23** with 313+ skills; **Claude Forge v3.0.2**
(May 3) bundled 11 agents / 40 commands / 15+ skills / 15 security
hooks; **Prismatic Skills** (May 4) added a vendor-specific bundle;
**Anthropic Cowork** introduced "Claude for Small Business" (May 14)
with a 15-workflow / 15-skill plugin pack. Auto-update edge cases
were also addressed: `package.json`-bearing plugins now auto-install
dependencies, the git clone timeout was raised 30 s → 120 s earlier
this cycle, and `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` lets corporate
machines skip SSH-key setup (2.1.141).

## Plugins

### claude-code-setup — first-party

- Source: <https://code.claude.com/docs/en/discover-plugins>,
  <https://github.com/anthropics/claude-plugins-official>
- Install: `/plugin install claude-code-setup@claude-plugins-official`
- License: Anthropic terms (in `claude-plugins-official` repo).

Analyses the current codebase and recommends tailored hooks, skills,
MCP servers, and subagents. Read-only analysis; will propose edits to
`CLAUDE.md` and `settings.json` but does not auto-write. Best-practice
baseline when spinning up a new repo. First-party.

### Language-server intelligence bundle — first-party

- Source: <https://github.com/anthropics/claude-plugins-official>
- Install: `/plugin install <lang>-lsp@claude-plugins-official` for
  `pyright`, `typescript`, `rust-analyzer`, `gopls`, `clangd`,
  `csharp`, `jdtls`, `kotlin`, `lua`, `php`, `swift`.
- License: Anthropic terms.

Adds automatic post-edit diagnostics and LSP-driven code navigation.
First-party. Requires the language-server binary on `$PATH`. Adds
zero context until invoked. Memory cost flagged in docs for
`rust-analyzer` and `pyright`.

### commit-commands / pr-review-toolkit / agent-sdk-dev / plugin-dev — first-party

- Source: <https://github.com/anthropics/claude-plugins-official>
- Install: `/plugin install <name>@claude-plugins-official`
- License: Anthropic terms.

`commit-commands` is the docs walkthrough plugin (git commit / push /
PR creation workflows). `pr-review-toolkit` adds specialised PR review
subagents. `agent-sdk-dev` is the toolkit for building with the Claude
Agent SDK. `plugin-dev` scaffolds new plugin development.

### External-integration bundle — first-party wrappers

- Source: <https://github.com/anthropics/claude-plugins-official/blob/main/.claude-plugin/marketplace.json>
- Install: `/plugin install <name>@claude-plugins-official` for
  `github`, `gitlab`, `atlassian`, `linear`, `notion`, `figma`,
  `vercel`, `firebase`, `supabase`, `slack`, `sentry`, `asana`.

Pre-configured MCP servers for each service. First-party wrappers;
the underlying MCP servers come from each vendor. Token impact
depends on enabled tools — defaults defer through tool-search; flip
`alwaysLoad: true` only for high-frequency tools.

### Prismatic Skills for Claude Code — third-party

- Source: <https://prismatic.io/blog/introducing-prismatic-skills-for-claude-code/>,
  coverage <https://www.devopsdigest.com/prismatic-skills-for-claude-code-released>
- Install: open-source release; consult repo for `/plugin marketplace
  add` instructions.
- License: stated open-source; SPDX not yet visible — verify before
  adopting.
- Date: announced 2026-05-04.

Five skills (CNI Builder, Component Builder, Embed Advisor, Orby,
Migration Analyzer) that turn Claude Code into a Prismatic
integration specialist. Pairs with the Prism MCP dev server. Useful
only if you build on Prismatic. Token cost is non-trivial — five long
skill bodies.

### Superpowers — third-party

- Source: <https://claude.com/plugins/superpowers>
- Install: `/plugin install superpowers@claude-plugins-official`
- License: MIT per repo.
- Coverage: <https://timewell.jp/en/columns/superpowers-claude-code-plugin>

7-phase TDD / debug / code-review / brainstorm / subagent framework.
Most-installed third-party plugin of the window. Public star counts
diverged across reports (one cited ~177K, an earlier source cited
~57K) — verify on the repo before quoting. Heavy: installs dozens of
skills, so it's the canonical use case for `skillOverrides`. Adds
many slash commands but does not modify `CLAUDE.md`.

### claude-mem — third-party

- Source: community marketplace; covered in
  <https://composio.dev/content/top-claude-code-plugins>
- License: see repo (commonly MIT — verify).

Long-term memory across sessions via SQLite + Chroma hybrid search.
Active. Writes a memory store under `~/.claude/` — privacy review
needed for shared machines. Adds context every turn (memory
retrieval injection); budget accordingly.

### Local-Review — third-party

- Source: community marketplace.
- License: verify on repo.

Runs ~5 review agents in parallel on the local diff and only surfaces
issues scored ≥ 80. Complements the new built-in `/code-review`
(which is single-pass). Spawns multiple subagents → multiplies token
cost; uses Bash, so impacted by `disableSkillShellExecution`.

### Claude Forge v3.0.2 — third-party

- Source: <https://github.com/sangrokjung/claude-forge>
- Install: `git clone` + run installer.
- License: MIT.
- Date: v3.0.2 released 2026-05-03 (v3.0.1 framed as "Anthropic 2026
  standard alignment"); 707 stars.

"oh-my-zsh for Claude Code": 11 agents, 40 commands, 15+ skills,
15 built-in security hooks. **Writes `settings.json`** (including
`disableSkillShellExecution`, `enabledMcpjsonServers`) and installs a
`CLAUDE.md` template with `@import`. Pins four MCP servers
(`playwright`, `context7`, `jina-reader`, `chrome-devtools@0.23.0`).
Audit the hooks (`remote-command-guard`, `db-guard`,
`output-secret-filter`) before enabling.

## Changelog items affecting plugins / skills (2.1.119 → 2.1.149)

- Sources:
  <https://code.claude.com/docs/en/changelog>,
  <https://github.com/anthropics/claude-code/releases>,
  <https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md>.

**Plugin discovery / install UX**

- **2.1.143** (May 15) — `/plugin` Browse/Discover shows **projected
  context cost** (per-turn token estimate).
- **2.1.144** (May 19) — `/plugin` Browse/Discover shows
  **last-updated date**.
- **2.1.145** (May 19) — `/plugin` Browse/Discover shows a complete
  **"Will install" pane** (commands, agents, skills, hooks, MCP /
  LSP servers) before install.
- **2.1.142** (May 14) — `/plugin` returns to the Installed list
  after enable/disable/uninstall.
- **2.1.143** — Plugin dependency enforcement: `claude plugin disable`
  refuses if another enabled plugin depends on the target;
  `claude plugin enable` force-enables transitive dependencies.
- **2.1.143** — Plugins with a root-level `SKILL.md` (and no `skills/`
  dir) are now surfaced as a skill.
- **2.1.141** (May 13) — `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` env var
  clones GitHub plugin sources over HTTPS (no SSH key).
- **2.1.129** (May 6) — `--plugin-url <url>` flag fetches a plugin
  `.zip` archive for the current session.
- **2.1.128** (May 4) — `--plugin-dir` accepts `.zip` archives;
  `workspace` is now a reserved MCP server name.
- **2.1.121** (Apr 28) — Added `claude plugin prune` to remove orphan
  auto-installed dependencies.
- **2.1.141** — Fixed plugins enabled only via project
  `.claude/settings.json` showing "not cached" errors.

**Skill loading semantics**

- **2.1.129** — `skillOverrides` setting now actually works: `off`
  hides from model and `/`; `user-invocable-only` hides from model;
  `name-only` collapses description.
- **2.1.121** — `/skills` got a type-to-filter search box.
- **2.1.120** (Apr 28) — Skills can reference current effort level
  via `${CLAUDE_EFFORT}` in content.
- **2.1.139** (May 11) — `/context` shows the providing plugin's name
  for plugin-sourced skills; per-skill token estimates use the model
  tokenizer.
- **2.1.147** (May 21) — Built-in `/simplify` skill **renamed to
  `/code-review`** with effort levels and `--comment` for inline
  GitHub PR comments.
- **2.1.145** — Fixed argument-hint / progressive arg suggestions not
  appearing for skills whose `name:` differs from directory basename.
- **2.1.145** — Fixed skills with `context: fork` repeatedly
  re-invoking themselves.
- **2.1.136** (May 8) — Fixed `plugin.json` `skills:` entry hiding
  the plugin's default `skills/` directory; file paths now error
  instead of failing silently.

**MCP behaviour**

- **2.1.147** — Fixed MCP servers with paginated `tools/list` only
  returning page 1 (tools silently dropped). Earlier ack in 2.1.143.
- **2.1.139** — `MCP_TOOL_TIMEOUT` raises per-request fetch timeout
  for remote HTTP/SSE servers (capped 60 s); `CLAUDE_PROJECT_DIR` is
  now exposed to stdio MCP servers.
- **2.1.128** — Reconnecting MCP servers no longer flood conversation
  with full tool lists.
- **2.1.121** — New MCP server option `alwaysLoad`: tools skip
  tool-search deferral when `true`.

**Hooks affecting plugin / skill flows**

- **2.1.149** (May 22) — `/usage` now shows per-category breakdown
  including skills, subagents, plugins, per-MCP-server cost.
- **2.1.145** — `Stop` / `SubagentStop` hook input now includes
  `background_tasks` and `session_crons` fields.
- **2.1.139** — New hook `args: string[]` (exec form, no shell);
  `continueOnBlock` for `PostToolUse`.
- **2.1.133** (May 7) — Hooks receive `effort.level` and
  `$CLAUDE_EFFORT`.
- **2.1.121** — `PostToolUse` hooks can replace tool output via
  `hookSpecificOutput.updatedToolOutput`.

**Settings / safety**

- **2.1.121 / 2.1.126** — `--dangerously-skip-permissions` now
  bypasses writes to `.claude/`, `.git/`, `.vscode/`, shell config
  files, and skips prompts for `.claude/skills|agents|commands`.
- **2.1.119** (Apr 23) — `/config` settings persist to
  `~/.claude/settings.json` with project/local/policy override
  precedence.

**Carried forward (predates the window — included because the
guidelines explicitly call them out)**

- `disableSkillShellExecution` and MCP
  `_meta["anthropic/maxResultSizeChars"]` (up to 500 KB) shipped in
  2.1.91 (early April 2026) per ClaudeCodeLog on X.

## Security and context-cost flags to surface to readers

- A cookie-stealer malware campaign and a leaked-source incident
  (TheRegister, TheHackerNews, TechRadar, early–mid May 2026)
  targeted users of fake Claude Code installers and unverified
  plugins. Reinforces the docs' warning: **plugins execute arbitrary
  code at your user privilege**.
- Vercel plugin consent-prompt controversy (TechRadar) — illustrates
  how third-party plugins can exfiltrate prompts. Recommend
  `disableSkillShellExecution: true` and `allowManagedHooksOnly:
  true` for shared / CI environments.
- The `/plugin` "Will install" pane (2.1.145+), the marketplace
  **Context cost** badge (2.1.143+) and **Last updated** badge
  (2.1.144+) are the easiest pre-install hygiene checks — every
  recommendation in this report should be re-verified against those
  panes before installing.
