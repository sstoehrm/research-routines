# Claude Code — 2026-07-04

## Summary

Between April 23 and July 4, 2026 the Claude Code plugin/skill ecosystem shifted from "install marketplaces" to "drop a folder and it works." v2.1.157 auto-loads any plugin in `.claude/skills/` without a marketplace and adds `claude plugin init` scaffolding; v2.1.152 introduced `/reload-skills`, `reloadSkills: true` on `SessionStart` hooks, and the `MessageDisplay` hook. Anthropic shipped its first free security plugin (`security-guidance`), added a bundled `/dataviz` skill on July 1, and continued expanding the official marketplace with partner plugins from Adobe, Airtable, Airwallex, Apollo GraphQL, Atlassian, Auth0, AWS (multiple), Azure, and others (marketplace is now well past the ~101 plugins reported in April). Nested `.claude/skills` directories, `disallowed-tools` frontmatter on skills, `disableBundledSkills`, `defaultEnabled: false`, and a plugin-renames map for zero-toil migrations all landed in the same window. Hooks and MCP got quieter but material fixes (hyphen exact-matching, `Bash,PowerShell` comma-matcher, comma-separated matcher regression, MCP OAuth retries, `claude mcp login/logout` CLI).

## Plugins

### security-guidance (Anthropic, official)

- Source: <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/security-guidance>
- Install: `/plugin install security-guidance@claude-plugins-official` then `/reload-plugins`
- License: Apache-2.0 (repo-level)

**What it does / why it matters:** Anthropic's first free, first-party security plugin. Reviews Claude's own code changes at three depths: (1) a zero-cost regex/substring per-edit `PostToolUse` check on `Edit`/`Write`/`NotebookEdit` for `eval`, `pickle`, `dangerouslySetInnerHTML`, `.github/workflows/` edits, etc.; (2) a background end-of-turn LLM diff review via a `Stop` hook that re-prompts Claude with findings; (3) an agentic cross-file review on `git commit`/`git push` (filtered `PostToolUse` on `Bash`). Requires Claude Code ≥ 2.1.144, Python 3.8, and a git repo; bootstraps a venv under `~/.claude/security/` on first run. Anthropic reports a 30-40% drop in security-related PR comments internally. Shipped week of May 25-29, 2026.

**Notes / caveats:** Registers `SessionStart`, `UserPromptSubmit`, `PostToolUse`, and `Stop` hooks. Extend with `.claude/claude-security-guidance.md` (guidance for the model reviewer, 8 KB cap) and `.claude/security-patterns.yaml|json` (regex/substring rules, 50-rule cap). Model reviews use Opus 4.7 by default (`SECURITY_REVIEW_MODEL`, `SG_AGENTIC_MODEL` to override). Commit reviews capped at 20/hour. Per-layer kill switches: `ENABLE_PATTERN_RULES`, `ENABLE_STOP_REVIEW`, `ENABLE_COMMIT_REVIEW`, `ENABLE_CODE_SECURITY_REVIEW`, `SECURITY_GUIDANCE_DISABLE`. Does not modify CLAUDE.md.

### commit-commands (Anthropic, official)

- Source: `claude-plugins-official` marketplace entry
- Install: `/plugin install commit-commands@claude-plugins-official`
- License: Apache-2.0

**What it does / why it matters:** Ships `/commit`, push, and full PR-creation flows as a single namespaced slash-command bundle so users no longer paste ad-hoc "make a commit and open a PR" prompts. Recommended by Anthropic as a starter alongside `security-guidance`. Meaningful because it replaces the CLAUDE.md commit conventions many teams were maintaining by hand.

**Notes / caveats:** No hooks; pure slash commands that shell out to `git` and `gh`. Behavior mirrors the built-in git commit / PR docs in Claude Code, so no CLAUDE.md changes needed.

## Skills

### /dataviz (bundled, Anthropic)

- Source: bundled with Claude Code 2.1.198 (July 1, 2026)
- Install: ships with Claude Code; no install step
- License: same as Claude Code

**What it does / why it matters:** Design guidance for any chart/graph/plot/dashboard the model produces, in any medium (HTML/React artifacts, matplotlib, Recharts, D3, inline SVG, Slack images). Includes a runnable color-palette validator (`references/palette.md`) that you swap for your brand. Triggers on chart-shaped requests and is intended to be read before writing chart code.

**Notes / caveats:** Skill runs no shell by default; the palette validator is opt-in. Adds tokens to the context on trigger, so `disableBundledSkills` / `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` (new in 2.1.169) is how to turn it off org-wide.

### /code-review (bundled, renamed May 21)

- Source: bundled; former `/simplify` was split
- Install: ships with Claude Code
- License: same as Claude Code

**What it does / why it matters:** In v2.1.147 Anthropic renamed the old `/simplify` to `/code-review` (correctness bugs at low/medium/high/max effort); in v2.1.152 `--fix` was added to apply findings to the working tree, and `--comment` posts findings as inline PR comments. In v2.1.154 a new `/simplify` skill was reintroduced as a cleanup-only pass (reuse/simplification/efficiency/altitude) that also applies fixes. This split — quality vs. correctness — is now the canonical Anthropic recommendation for pre-commit and pre-PR review.

**Notes / caveats:** `--comment` requires `gh` auth; `--fix` writes to your tree. `/review <pr>` was rewired in 2.1.186 to reuse the `/code-review medium` engine.

### /simplify (bundled, cleanup-only, reintroduced May 28)

- Source: bundled with 2.1.154
- Install: ships with Claude Code
- License: same as Claude Code

**What it does / why it matters:** Quality-only companion to `/code-review`. Won't hunt for bugs — instead reviews the changed code for dead code, duplication, and simpler shapes and applies the fixes. Meant for the "clean up before I commit" step users were writing manually.

**Notes / caveats:** Modifies the working tree — not just review comments.

### /verify (bundled)

- Source: bundled
- Install: ships with Claude Code
- License: same as Claude Code

**What it does / why it matters:** End-to-end verification skill that drives the affected flow (not just tests/typecheck) before you commit a nontrivial change. Auto-bootstraps a project-specific verify skill if none exists. Explicitly refuses to run on diffs that only touch tests/docs. Part of the same "quality gate at commit" tier as `/code-review` and `/simplify`.

**Notes / caveats:** Runs the app — expect network calls and side effects unless sandboxed.

### /reload-skills + `reloadSkills` SessionStart hook (2.1.152)

- Source: <https://code.claude.com/docs/en/skills>
- Install: bundled command
- License: same as Claude Code

**What it does / why it matters:** `/reload-skills` re-scans skill directories without restarting; `SessionStart` hooks can now return `{ hookSpecificOutput: { reloadSkills: true } }` to force a rescan when the hook installs skills. Skills authors and the `session-start-hook` skill rely on this to make freshly-cloned skills available inside the current session.

**Notes / caveats:** Watch for the 2.1.183 fix — rc-file slowness was causing skills to silently not load; skills authors should test skill discovery under slow shells.

### Karpathy Behavioural Skill (community, trending)

- Source: distributed as a single `SKILL.md`, mirrored across community repos and packaged in several third-party marketplaces
- Install: drop into `~/.claude/skills/` (auto-loaded since 2.1.157)
- License: varies by mirror (mostly MIT)

**What it does / why it matters:** A one-file skill that encodes four behavioral rules Andrej Karpathy called out about LLM coding pitfalls in January 2026. Reported to be the fastest-growing individual skill of the last quarter (aggregator star counts are in the six-figure range across mirrored copies, so treat exact numbers as ballpark). Notable as the first "philosophy skill" — no tooling, no MCP, just a curated behavioral instruction set — to hit mainstream adoption.

**Notes / caveats:** No shell, no CLAUDE.md edits. Adds a modest token overhead to every session where it's active.

### session-start-hook (bundled skill)

- Source: bundled skill
- Install: ships with Claude Code
- License: same as Claude Code

**What it does / why it matters:** Bundled skill that creates and develops SessionStart hooks so a project can run tests and linters during Claude Code on the web. Paired with the new `reloadSkills: true` return value from `SessionStart`, it's how you make a fresh clone self-configure.

**Notes / caveats:** Writes to `.claude/settings.json` and adds hook scripts under `.claude/`. Users should review before committing.
