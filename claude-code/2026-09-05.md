# Claude Code — 2026-09-05

## Summary

The late July → early September 2026 window (v2.1.220 → v2.1.261) was
dominated by (1) the **`/design` skill research preview** shipped in
v2.1.234 that brings Claude Design's artboard workflow into the CLI on
top of artifacts; (2) two new **hook events — `PreModelSwitch` and
`PostModelSwitch`** in v2.1.251 that can block / confirm / annotate a
model switch; (3) two new marketplace-plumbing features —
**`archive` plugin sources** with optional SHA-256 pin (v2.1.224) and
**plugin marketplace `command` sources** (v2.1.229) plus a
`headersHelper` on URL marketplaces (v2.1.238); (4) `managedMcpServers`
(v2.1.259) letting organizations push HTTP/SSE MCP servers to every
user; and (5) a **`/skill-doctor` command** (v2.1.261) that surfaces
loaded-but-unused skills and their context cost. A `--restricted` flag
(v2.1.248) and `permissions.blockReadsOutsideWorkingDirectories`
(v2.1.257) tightened the sandbox; the `workflow-authoring` bundled
skill (v2.1.248) cut the Workflow tool's prompt footprint from ~5.7k
to ~1k tokens. In the Anthropic-managed marketplace no new Anthropic-
authored plugins landed, but ~13 external partner plugins were added
(unity, mongodb-atlas, superdesign, google-cloud-storage,
crowdstrike-falcon-fusion, activecampaign, scandit-sdk, …).
**Superpowers v6.3.0** (Aug 12) added Devin CLI / Hermes Agent harness
support and same-shape task batching. **Caveman** shipped five point
releases in the window (v2.2.0 → v2.6.0) plus a Firefox extension
port and an ASD-STE100 clarity register; `cavekit` was frozen with
active development moved to the `caveman` family. Two silent-break
items to watch: v2.1.261 made `keybindingFlavor` a no-op (word-editing
keys now always Bash-style), and v2.1.251 rejected plugin components
that point outside their plugin directory via symlink.
