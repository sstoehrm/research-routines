# Claude Code — 2026-05-09

## Summary

The two and a half weeks since the prior report were the heaviest
plugin-marketplace cycle to date for `anthropics/claude-plugins-official`:
roughly **40+ new plugins added** (Apr 23 batch through May 7) and a
**simultaneous 16-plugin removal sweep** on May 7 driven by quality and
security checks. Notable additions span enterprise (Vanta, Zscaler,
42Crunch, JFrog, CrowdStrike Falcon Foundry), data (Snowflake Cortex,
Oracle Data Platform, Aiven, ClickHouse, Qdrant, Zilliz, Pigment), dev
tooling (Apollo, Quarkus, Twilio, ServiceNow SDK, SAP MDK, AWS Dev
Toolkit, AWS Agents / Bedrock AgentCore), and observability (Logfire,
Fullstory, Dash0). On the changelog side, **plugins can now ship themes
and have hooks invoke MCP tools directly**; **`claude ultrareview
[target]`** is now a non-interactive subcommand for CI; the `/skills`
menu gained **type-to-filter search**; **`skillOverrides`** went from
defined-but-broken to actually-working with three modes; `--plugin-url`
allows fetching a plugin `.zip` for a single session; and **MCP servers
in `.mcp.json` no longer silently disappear after `/clear`** — a
long-standing pain point. Outside Anthropic the biggest item is
**Prismatic Skills for Claude Code** (announced May 4), an
open-source plugin with five integration-platform skills.

## Changelog items that affect plugins / skills

Source: <https://code.claude.com/docs/en/changelog>.

- **v2.1.118** (Apr 23) — Plugins can ship **themes** via a `themes/`
  directory; **hooks can invoke MCP tools directly** via
  `type: "mcp_tool"`; new `claude plugin tag` command for release
  tagging with version validation; auto-mode rule lists accept
  `"$defaults"` to extend (not replace) built-ins.
- **v2.1.119** (Apr 23) — `/config` settings now persist to
  `~/.claude/settings.json` with full precedence; `--agent <name>`
  honors `permissionMode`; PostToolUse / PostToolUseFailure hook input
  gains `duration_ms`; `blockedMarketplaces` now correctly enforces
  `hostPattern` / `pathPattern` (security fix); fix for `/skills`
  Enter key not pre-filling `/<skill-name>`.
- **v2.1.120** (Apr 28) — **`claude ultrareview [target]`
  non-interactive subcommand** for CI / scripting use; skills can
  reference `${CLAUDE_EFFORT}`.
- **v2.1.121** (Apr 28) — **`claude plugin prune`** + `plugin
  uninstall --prune` cascade for orphaned auto-deps; **type-to-filter
  search box in `/skills`**; PostToolUse `hookSpecificOutput.updatedToolOutput`
  extended from MCP-only to all tools; `--dangerously-skip-permissions`
  no longer prompts for writes to `.claude/skills/`,
  `.claude/agents/`, `.claude/commands/`; new MCP `alwaysLoad` option
  to bypass tool-search deferral.
- **v2.1.122** (Apr 28) — Fix for `/plugin` marketplace failing on
  entries with unrecognized source format.
- **v2.1.126** (May 1) — **`skillOverrides` setting now actually
  works**: `off` / `user-invocable-only` / `name-only`;
  `claude_code.skill_activated` OTel event now fires for user-typed
  slash commands with `invocation_trigger`; `claude project purge
  [path]` clears all per-project Claude Code state.
- **v2.1.128** (May 4) — `skillOverrides` rollout continued; `/plugin
  update` now correctly detects new versions of npm-sourced plugins;
  `/plugin` Components panel fix for `--plugin-dir` loaded plugins.
- **v2.1.129** (May 6) — **`--plugin-url <url>`** flag to fetch a
  plugin `.zip` for the current session; `--plugin-dir` accepts `.zip`
  archives; **plugin manifests should declare `themes` and
  `monitors` under `"experimental": { ... }`** (top-level still
  works but `claude plugin validate` warns).
- **v2.1.132** (May 6) — Fix for plugin uninstall and enable / disable
  not matching slugs case-insensitively; fix for plugin slash commands
  with spaces (`/myplugin review`) not resolving.
- **v2.1.133** (May 7) — Hooks now receive active effort level via
  `effort.level` JSON input field and `$CLAUDE_EFFORT`; subagents can
  again discover project / user / plugin skills via the Skill tool
  (regression fix).
- **v2.1.136** (May 8) — **MCP servers in `.mcp.json`, plugins, and
  claude.ai connectors no longer silently disappear after `/clear`**;
  plugin `Stop` / `UserPromptSubmit` hooks no longer fail when cache
  cleanup deletes an in-use version; **plugin marketplace removal key
  changed from `r` to `d`** (UI consistency).
