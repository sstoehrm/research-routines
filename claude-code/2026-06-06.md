# Claude Code — 2026-06-06

## Summary

Since the 2026-04-23 report, the plugin and skill ecosystem matured
along five axes:

1. **First-party plugins**: Anthropic shipped **`security-guidance`**
   (May 27), a three-layer vulnerability reviewer that runs locally
   via hooks and on-demand model review. The official marketplace
   also picked up **`session-report`**, **`claude-md-management`**,
   **`hookify`**, **`mcp-tunnels`**, **`ralph-loop`**,
   **`code-modernization`**, **`pr-review-toolkit`**, and several
   language LSP plugins (Kotlin, Lua, PHP, Ruby, etc.), reaching
   roughly **36 internal + 16+ external** entries in the `plugins/`
   and `external_plugins/` trees, with the full `marketplace.json`
   listing growing well past the April count (cited as ~150–177
   plugins by community trackers as of June).
2. **Plugin loading semantics changed**: as of v2.1.157 (May 29),
   **plugins in `~/.claude/skills/<name>/` auto-load with no
   marketplace**, and `claude plugin init <name>` scaffolds the
   directory. `defaultEnabled: false` (v2.1.154) lets a plugin
   install without activating. Plugin dependency enforcement landed
   in v2.1.143 (May 15).
3. **Skill management got real controls**: `/reload-skills`,
   `SessionStart hookSpecificOutput.reloadSkills`, `MessageDisplay`
   hook, `disallowed-tools` in skill frontmatter (all v2.1.152, May
   27), plus the **`skillListingBudgetFraction`** setting and
   `skillOverrides` (`off` / `user-invocable-only` / `name-only`) to
   clamp the per-skill ~75–150 token "context tax."
4. **Community marketplaces consolidated**: the official
   **`anthropics/claude-plugins-community`** read-only mirror became
   the canonical community catalog (submissions via
   `clau.de/plugin-directory-submission`), alongside continued growth
   of `jeremylongshore/claude-code-plugins-plus-skills` (425 plugins
   / 2,810 skills, v4.33.0 May 25–26) and `davepoon/buildwithclaude`.
5. **Two security stories**: **(a)** Anthropic's own GitHub Action
   (`claude-code-action`) had a prompt-injection / `[bot]` actor
   bypass (CVSS 7.8) patched in **v1.0.94** in early June — relevant
   to plugins that ship a GitHub Action wrapper; **(b)** community
   measurements reported skill/plugin context loads of ~23k tokens
   per session in unaudited setups, driving the new budget knobs.

## Plugins

### security-guidance (Anthropic, new)

- Source:
  <https://github.com/anthropics/claude-plugins-official>
  (`plugins/security-guidance`),
  <https://www.helpnetsecurity.com/2026/05/27/anthropic-claude-code-security-guidance-plugin/>,
  <https://www.securityweek.com/anthropic-releases-new-claude-sandbox-security-guidance-plugin/>
- Install: `/plugin install security-guidance@claude-plugins-official`,
  then `/reload-plugins`.
- License: per Anthropic-managed marketplace (LICENSE in plugin
  directory; free for all users/plans).
- What it does / why it matters: three-layer review pipeline — (1)
  **per-edit** deterministic regex pattern check for ~25 dangerous
  patterns (`eval`, `new Function`, `os.system`,
  `child_process.exec`, pickle, `dangerouslySetInnerHTML`,
  `.innerHTML=`); (2) **end-of-turn** model-based review; (3)
  **commit/push** deep agentic review touching surrounding files.
  Project rules in `.claude/claude-security-guidance.md`. Anthropic
  reports 30–40% reduction in security-related PR comments
  internally.
- Notes / caveats: requires Claude Code **≥ v2.1.144** and Python
  ≥ 3.8. Pattern-check layer adds zero model cost; deeper layers
  consume tokens. Plugin writes findings into Claude's context and
  into commit/push hook pipelines — adds **PreToolUse / PostToolUse
  hooks** that fire on `Edit`, `Write`, and Bash `git commit` / `git
  push`.

### claude-code-action v1.0.94 patch (security item)

- Source:
  <https://flatt.tech/research/posts/poisoning-claude-code-one-github-issue-to-break-the-supply-chain/>,
  <https://thehackernews.com/2026/06/claude-code-github-action-flaw-let-one.html>,
  <https://www.microsoft.com/en-us/security/blog/2026/06/05/securing-ci-cd-in-agentic-world-claude-code-github-action-case/>
- Affected: `anthropics/claude-code-action` < v1.0.94 (the official
  GitHub Action that wraps Claude Code). The vulnerability itself
  isn't a plugin, but every plugin or workflow that runs Claude Code
  in CI inherits the surface.
- Severity: CVSS v4.0 **7.8**.
- Fix: v1.0.94 adds `checkHumanActor` to agent mode, scrubs env vars
  from child processes, disables workflow summary by default, custom
  `gh` wrapper that blocks exfil URL patterns, ignores issues edited
  after workflow trigger.

## Skills

### `/reload-skills` (built-in, new in v2.1.152, May 27)

- Source: <https://code.claude.com/docs/en/changelog>,
  <https://dev.classmethod.jp/en/articles/20260524-claude-code-updates-v2-1-152/>
- Install: ships with Claude Code; no plugin required.
- License: bundled (proprietary Anthropic).
- What it does / why it matters: re-scans skill directories
  mid-session without restart. Pairs with `SessionStart` hooks
  returning `hookSpecificOutput.reloadSkills: true` to make
  hook-installed skills immediately available.

### `disallowed-tools` in skill frontmatter (built-in, v2.1.152)

- Source: <https://code.claude.com/docs/en/changelog>
- What it does / why it matters: skill SKILL.md frontmatter can now
  list `disallowed-tools` to *remove* tools from the model while the
  skill is active (e.g. forbid `Bash` while a research skill runs).
- Notes / caveats: useful for sandboxing risky skills; complements
  `disableSkillShellExecution` shipped in April.

### `MessageDisplay` hook (built-in, v2.1.152)

- Source: <https://code.claude.com/docs/en/hooks>
- What it does / why it matters: lets a hook transform or hide the
  rendered text of an assistant message. **Display-only**: transcript
  and what Claude sees keep the original text.
- Notes / caveats: fires per streamed text chunk; default 10 s
  timeout. Not a security boundary (Claude still sees the unmodified
  text).

## Open questions / follow-ups

- **Exact official marketplace plugin count**: WebFetch couldn't
  fully enumerate `marketplace.json` (file is ~3000 lines / 123 KB).
  Community trackers cited "~150" to "~177" entries by early June;
  worth pulling the raw JSON next routine to get an exact A/B count
  of `plugins/` vs `external_plugins/`.
- **Real token impact of the new auto-load (`~/.claude/skills/`)**:
  now that *every* directory there is treated as a plugin, users
  have reported orphaned/disabled-plugin context overhead. Worth
  measuring after v2.1.157 with `/usage` per-category and `/context
  all`.
- **`security-guidance` interactions with hooks**: confirm whether
  its PreToolUse/PostToolUse hooks interact with
  `disableSkillShellExecution` set by users, and whether the
  on-commit deep review is cancellable.
- **`claude-code-action` v1.0.94 patch adoption**: many partner
  plugins in `external_plugins/` ship Actions or workflow templates
  — track whether they pin a safe minimum version.
- **`skillListingBudgetFraction` defaults vs. real workloads**: the
  1% default truncates descriptions for users with 50+ skills;
  community-reported "23k token waste" figures need an independent
  measurement.
- **`pluginSuggestionMarketplaces` rollout**: enterprise allowlisting
  landed in v2.1.152 but admin tooling (UI, docs) was incomplete as
  of writing — worth re-checking.
- **Status of `wshobson/agents` marketplace**: surfaced in some
  community lists as a major aggregator but didn't clearly trace to
  a maintained homepage in this round; verify next time.
- **Community marketplace catalog freshness**:
  `anthropics/claude-plugins-community` mirror has only 32 commits
  and the sync timing from the internal review pipeline is opaque
