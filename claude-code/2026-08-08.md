# Claude Code — 2026-08-08

## Summary

The two weeks since the 2026-07-25 report were dominated by CLI plumbing,
not blockbuster skills. Claude Code shipped **v2.1.220 → v2.1.224** with
several plugin/skill semantics changes: a new **`archive` plugin source**
(zip over HTTPS with optional `sha256` pin), a change to **`context: fork`
skills** that now run in the background by default, boolean frontmatter
that accepts `yes`/`no`/`on`/`off`, marketplace allowlist wildcards
(`owner/*`), `/plugin install` catalog auto-refresh, and no more mandatory
`/reload-plugins` for a fresh install. Two Bash permission-bypass fixes
also landed. On the official marketplace, Anthropic merged **four new
plugins on 2026-08-07** — `airwallex-dev`, `salesforce-development`,
`streaming-skills-plugin`, and `synthflow` — and migrated **context7** to
a remote MCP server. The community marketplace added ~30 plugins across
the window (notably **prismatic-skills**, **xsolla-ai-kit**, **credible**,
**cala**, **meticulous**, **synthflow-mcp**). The highest-momentum
independent skill launch adjacent to the window is Peter Yang's
**no-ai-slop** (published 2026-07-22, ~1k stars within a day). The **ccpi**
catalog kept growing to ~**471 plugins / 3,179 skills / 347 agents**;
**wshobson/agents** had no commits in-window. Items the previous report
flagged for cross-check — `disableSkillShellExecution`, MCP
`maxResultSizeChars`, `/ultrareview` — all shipped in April 2026 and have
no material changes in this window.

## Changelog items that affect plugins / skills

Source for all: <https://code.claude.com/docs/en/changelog> and
<https://github.com/anthropics/claude-code/releases>.

### v2.1.224 (2026-08-07)

- **New `archive` plugin source** — install plugins from a zip over HTTPS
  with no git or npm dependency; optional `sha256` pin, and the digest
  becomes the plugin's version identifier. Docs:
  <https://code.claude.com/docs/en/plugin-marketplaces#zip-archives>
- **Skill semantics change** — skills with `context: fork` now run in the
  background by default. Opt out per skill with `background: false`.
  **Any skill that assumed foreground fork behavior needs this flag** or
  the workflow changes. Because a forked background skill applies edits
  outside session checkpoints, `/rewind` will not undo them — use git.
- **Boolean frontmatter** — fields like `disable-model-invocation` now
  accept `yes`/`no`/`on`/`off`/`1`/`0` (any case) in addition to
  `true`/`false`. Older Claude Code versions accepted only `true`/`false`,
  so pin your minimum Claude Code version if you emit these forms.
- `claude self-hosted-runner` — turn your own machine/container into a
  runner for Claude Code web/mobile/desktop sessions (Team & Enterprise
  plans).
- Fixed: plugin install records being corrupted when the same plugin is
  installed in multiple projects.
- Fixed: MCP tools connecting mid-turn being deferred for tool search
  without their names announced to the model.
- Sandbox credential masking gained `extract` / `onExtractNoMatch`,
  JWT-aware masking with `decode: "jwt"` + `maskClaims`, and AWS SigV4
  re-signing via `awsPairs` / `sigv4`.

### v2.1.223 (2026-08-05/06)

- **Marketplace allowlist wildcards** — `strictKnownMarketplaces` and
  `blockedMarketplaces` managed settings now accept `"owner/*"` to allow
  or block every marketplace repo under a GitHub org.
- `claude plugin validate` warns when a marketplace or plugin name would
  be rejected by Claude Desktop's managed marketplace sync.
- **New `/prompt-audit`** on the `claude-api` skill (see Skills above).
- **Security fixes**:
  - Bash permission-bypass fix (crafted commands could hide parts of
    themselves from permission checks).
  - Permission prompts hardened against tab / invisible-Unicode padding.
  - Workflow scripts can no longer escape the sandbox via dynamic
    `import()`.
- Gateway model discovery fix for provider-prefixed IDs
  (`vertex_ai/claude-*`, `bedrock/anthropic.claude-*`).

### v2.1.222 (2026-08-04)

- **Plugin skills path** — plugins may now specify `"."` as a `skills`
  path; the root-level `SKILL.md` validation error now suggests using the
  plugin root as the fix.
- **Plugin activation** — plugins installed via `/plugin` activate
  immediately when safe; no more mandatory `/reload-plugins`.
- Background sessions now commit/push to preserve work, open draft PRs
  only when the task calls for one, and follow `CLAUDE.md` git
  instructions.
- Fixed: worktree-isolated sessions and their subagents being able to run
  destructive git commands against the main checkout.
- Fixed: `PreToolUse` auto-allow hooks bypassing tool restrictions in
  background agent tasks (summaries, compaction, renames). **Any hook
  that quietly relied on that side-channel stops working.**

### v2.1.221 (2026-08-03/04)

- New **Focus view** (`Ctrl+Alt+F`) collapses tool activity into per-turn
  summaries — changes how skill invocations appear in chat.
- Sandbox `mode: "mask"` for credential files on Linux/WSL — sandboxed
  commands read a sentinel copy while the sandbox proxy substitutes real
  values on egress.
- Refusal when Claude tries to invoke a `disable-model-invocation` skill
  now instructs Claude to ask the user to run the skill rather than
  replicating its workflow.
- `/plugin install` now refreshes stale marketplace catalogs and retries
  before reporting a plugin not found. Reduces false negatives when the
  local mirror is behind.
- Sessions forked with `/fork` now create their own worktree.
- Fixed: skills not being callable in non-interactive sessions.
- Fixed: zsh regex-conditional Bash permission bypass.

### v2.1.220 (2026-07-25)

- Bug fixes and reliability only — no plugin/skill surface changes.

### v2.1.219 (2026-07-24, just before the window — for continuity)

- `sandbox.network.strictAllowlist` denies non-allowlisted hosts without
  prompting.
- New `DirectoryAdded` hook fires after `/add-dir` or SDK
  `register_repo_root` registers a new working directory mid-session.
- Subagents can spawn nested subagents up to depth 3 by default (was 1);
  set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` to disable.
- Nested-subagent forwarding in stream-json when `--forward-subagent-text`
  is set.
- Added `workflowSizeGuideline` settings key.
- Claude Opus 5 becomes the default Opus model with 1M context window.
- `/skills` gained a type-to-filter search box; earliest reference lands
  in this window.

## Permissions / trust posture reference

- **`anthropics/claude-plugins-official`** — Apache-2.0, ~33.2k stars,
  Anthropic-vetted. Still requires the user to trust each individual
  plugin at install time.
- **`anthropics/claude-plugins-community`** — read-only mirror; submit at
  clau.de/plugin-directory-submission. Passes automated validation and
  safety screening but is **not human-vetted**.
- **CCPI / tonsofskills** — entirely community-curated, no Anthropic
  vetting. Treat as third-party.
- Project-scope `@skills-dir` plugins load only after workspace trust;
  MCP servers they declare still go through per-server approval as with
  project `.mcp.json`; background monitors do NOT load in project scope.
