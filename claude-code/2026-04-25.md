## Plugins

### claude-mem — persistent memory (new findings)

- Source: <https://github.com/thedotmack/claude-mem>
- Install: `npx claude-mem install`, or via plugin marketplace.
- License: see repo.

Still hooks into Claude Code's session lifecycle, compresses with
Claude's agent-SDK, and stores in SQLite + Chroma. New this cycle:
a reported **~65.8K stars** (up from ~46.1K on 2026-04-07) and a
**community security audit** flagging the local **HTTP API on port 37777
as unauthenticated** — any local process can read captured observations,
read settings (including cleartext API keys), and inject arbitrary
memories. Treat the risk as HIGH for shared or multi-user machines until
upstream lands auth. Sensitive data is stored in the OS keychain, but the
HTTP endpoint bypasses that.

### caveman — token-compression skill (updated measurements)

- Source: <https://github.com/JuliusBrussee/caveman>
- Install: `/caveman` (intensity modes: `lite`, `full`, `ultra`).
- License: see repo (URL not verified).
- Reported stars: ~560 after ~2 weeks.

Unchanged in mechanics but the numbers on it are converging. Field
measurements are landing closer to **15–25% output-token reduction** on
real tasks rather than the original headline 75%. A March 2026 paper
cited in community coverage does report a separate **+26 pp accuracy
gain** on 1,485 verbose-error problems. Generated code is still untouched;
prose style shift is the main caveat before using on externally-visible
commits or PR bodies.

### connect-apps — 500+ SaaS actions

- Coverage: <https://composio.dev/content/top-claude-code-plugins>
- License / source URL: not verified in primary sources.

Integrates Claude Code with 500+ SaaS services (GitHub, Slack, Gmail,
Notion, etc.) and turns them into first-class tool calls. Listed in April
2026 trackers as one of the most-installed non-Anthropic plugins.
Permissions footprint is wide — authorise with care and prefer running
with `disableSkillShellExecution` if possible.

### security-sweep — security scanner plugin

- Coverage: <https://composio.dev/content/top-claude-code-plugins>
- Source URL: not verified in primary sources.

Bundles scans against OWASP Top 10 (2025), OWASP Mobile Top 10 (2024),
and OWASP LLM Top 10 (2025). Detects hardcoded secrets, injection flaws,
auth/config issues, and LLM-specific misuses. Complementary to
`/ultrareview` rather than a replacement — different coverage model.

### CodeRabbit — external-reviewer plugin

- Source: <https://github.com/anthropics/claude-plugins-official/blob/main/.claude-plugin/marketplace.json>
- Install: via the official marketplace.

Now visible in the official partner marketplace. Runs AI + 40+ static
analyzers as an external reviewer — complementary to `/ultrareview`'s
internal multi-agent critique, useful as a second opinion when the same
agent family might share blind spots.

## Skills

### /less-permission-prompts (v2.1.111, 2026-04-16)

- Source: <https://code.claude.com/docs/en/changelog>

Either a rename or an evolution of the earlier `/fewer-permission-prompts`
skill from the prior report. Same mechanism: scans recent transcripts for
frequent read-only Bash and MCP calls and proposes a prioritised allowlist
for `.claude/settings.json`. Modifies `settings.json` directly — safe but
note the write.

### /ultrareview (v2.1.101, 2026-04-10)

- Coverage: <https://releasebot.io/updates/anthropic/claude-code>

Unchanged in purpose (parallel multi-agent cloud review of the current
branch or a specified PR), but the version-bump entry is new. Remains
user-triggered and billed per run. No local equivalent yet.

### `$CLAUDE_EFFORT` inside skills (v2.1.120, 2026-04-25)

- Source: <https://code.claude.com/docs/en/changelog>

Skills can reference the current effort level at render time
(`low` / `medium` / `high` / `xhigh` / `max`). This is small but unlocks
a real pattern: skills that budget their own token spend and reasoning
depth based on effort. Flag for any skill you write this week — it is a
newly-available variable.

### Hook → MCP direct invocation (v2.1.118, 2026-04-23)

- Source: <https://code.claude.com/docs/en/changelog>

Hooks can now invoke MCP tools directly with `type: "mcp_tool"`, removing
the need for wrapper scripts that shell out to `claude mcp run`. Changes
what a skill's hook layer can do — particularly for skills that were
previously blocked by `disableSkillShellExecution`.

### Plugin-shipped themes (v2.1.118, 2026-04-23)

- Source: <https://code.claude.com/docs/en/changelog>

Plugins may now ship a `themes/` directory. Minor on its own, but it
means cosmetic plugins are a category now, which has implications for the
marketplace curation story.

## Changelog items that affect plugins / skills (2026-04-10 → 2026-04-25)

Source for all entries: <https://code.claude.com/docs/en/changelog>;
corroborated against <https://releasebot.io/updates/anthropic/claude-code>
and <https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md>.

- **v2.1.101 (2026-04-10)** — `/ultrareview` changelog entry.
- **v2.1.111 (2026-04-16)** — `/less-permission-prompts` surfaced as a
  first-party skill.
- **v2.1.118 (2026-04-23)** — plugin-shipped themes (`themes/`); hook

- **v2.1.119 (2026-04-23)** — external `userConfig` prompts with

  install / update / refresh / autoupdate. **Known bug**: `userConfig`

  "Configure options" manually. Tracked in open issues (#39455, #39827).

  content; `claude plugin validate` accepts `$schema`, `version`,
  `description` at the top level of `marketplace.json` and `$schema` in
  `plugin.json`.

## Open questions / follow-ups

- **caveman token-savings baseline** — 65–75% headline vs. 15–25% in the
  field. What workload profiles consistently hit >50%? A targeted
  measurement on our typical coding sessions (diff sizes, commit messages,
  PR bodies) would settle it.
- **claude-mem vs. filesystem baseline** — unchanged from the prior
  report. Added urgency now: the port-37777 auth gap means the
  comparison should include a "just dump last N transcripts to disk"
  control that does not open a local HTTP listener.
- **Anthropic-vs-partner plugin ratio** — steady at ~33/68. Monitor
  whether any April releases change this.
- **`/ultrareview` local equivalent** — still none shipped. With hooks
  now able to invoke MCP tools directly (v2.1.118), a hook-driven local
  parallel-review skill is now possible — worth prototyping.
- **v2.1.119 `userConfig` prompt bug** — check the next patch release
  for a fix before relying on `sensitive: true` for plugin secrets.
- **Hook → MCP circular calls (v2.1.118)** — a hook calling an MCP tool
  whose server re-triggers the same hook is now syntactically possible.
  Check whether docs add guardrails or whether it is left to plugin
  authors to avoid.
