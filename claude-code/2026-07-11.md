# Claude Code — 2026-07-11

## Summary

Between late April and mid-July 2026 the plugin and skill ecosystem grew substantially. Anthropic's official marketplace crossed 200+ plugins, launched the first-party `security-guidance` plugin (May 27), and added `/dataviz` as a new bundled skill (v2.1.198, June 30). The skill and plugin machinery itself was heavily reworked — a `MessageDisplay` hook, `/reload-skills`, `disallowed-tools` frontmatter, `defaultEnabled: false` plugins, plugin auto-load from `.claude/skills`, `claude plugin init` scaffolding, `claude mcp login/logout`, a `/plugin` marketplace search bar, nested-skill loading, stacked-skill invocation, and `/config key=value` for prompt-driven settings all landed in this window. Third-party leaders (Superpowers, Caveman, Context7, Frontend Design) accumulated hundreds of thousands of installs, and independent marketplaces like `obra/superpowers-marketplace` kept publishing bleeding-edge versions ahead of the Anthropic-curated fork. Two changes are permission-sensitive: v2.1.207 rejects `${user_config.*}` in shell-form plugin hooks (shell-injection fix) and v2.1.207 no longer reads plugin option values from project-level `.claude/settings.json`.

## Plugins

### security-guidance (Anthropic, first-party)

- Source: <https://github.com/anthropics/claude-code/tree/main/plugins/security-guidance>
- Install: `/plugin install security-guidance@claude-plugins-official`
- License: Anthropic (bundled with Claude Code repo)

Launched May 27, 2026 (Week 22 digest / v2.1.150–v2.1.157 window). Runs a three-layer security review while Claude writes code: a fast pattern check on each edit, a model review at the end of each turn, and a deeper agentic review on commit or push. Catches injection, unsafe deserialization, unsafe DOM APIs, etc. Free on all plans; instant checks add no model cost. Project rules go in `.claude/claude-security-guidance.md`. Note: this modifies the commit/push loop — it can add multi-minute latency at push time on large diffs. Reference: <https://code.claude.com/docs/en/security-guidance>

### Superpowers (obra/superpowers-2, third-party, mirrored to official)

- Source: <https://github.com/obra/superpowers> (bleeding-edge marketplace: <https://github.com/obra/superpowers-marketplace>)
- Install: `/plugin install superpowers@claude-plugins-official` (curated) or add `obra/superpowers-marketplace` for latest
- License: MIT

Not new, but experienced explosive growth in the reporting window: ~752K installs by June 1, 2026 (second only to `frontend-design` at ~829K); repo reportedly north of 200K GitHub stars by late June. Bundles skills + hooks enforcing red/green TDD, YAGNI/DRY, parallel task execution, systematic debugging, and subagent-driven code review. Caveat: heavily rewrites the working loop, spins up git worktrees, and installs hooks — read the plugin.json before enabling in an org repo. Reference: <https://claude.com/plugins/superpowers>

### frontend-design (Anthropic, first-party)

- Source: <https://claude.com/plugins/frontend-design> (in claude-plugins-official)
- Install: `/plugin install frontend-design@claude-plugins-official`
- License: Anthropic

Already in the ecosystem before this window, but growth is the story: ~300K installs by late April, ~829K by June 1, 2026 — now the most-installed Claude Code plugin. Forces a purpose/tone/constraints/differentiation framework before writing CSS to escape the "Inter + purple gradient" default aesthetic. No hook or CLAUDE.md changes.

### Caveman (juliusbrussee/caveman) — leading 7-day install velocity

- Source: <https://github.com/juliusbrussee/caveman>
- Install: via community marketplace; the Anthropic-curated variant is also installable
- License: MIT

Caveat: cuts output tokens ~65% but *adds* ~1–1.5K input tokens per turn and doesn't affect thinking tokens. Reference: <https://www.claudepluginhub.com/blog/trending-claude-plugins-june-2026>

### Context7 (Upstash, third-party MCP)

Notable because it's third-party but distributed through the Anthropic marketplace. Adds one MCP server; no hooks or settings.json changes.

## Skills

### /dataviz (built-in bundled skill)

- Source: bundled in Claude Code v2.1.198
- Install: automatic (opt out via `disableBundledSkills` in settings.json, added v2.1.169)
- License: Anthropic

Announced June 30, 2026 in v2.1.198. Loads chart and dashboard design guidance into context: chart-type selection, layout rules, visual hierarchy, and a runnable color-palette validator so Claude can programmatically check contrast/accessibility rather than guess. Triggers automatically on chart/plot/dashboard requests. Because it's bundled, it counts against context; use `disableBundledSkills: true` or `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS=1` if unwanted.

### Nested-directory skills (loading semantics change)

- Source: v2.1.178/179 (June 15–16, 2026)
- Install: automatic — put SKILL.md files in nested `.claude/skills/<subdir>/`
- License: n/a (harness feature)

Skills in nested `.claude/skills/` directories now load; on name collision the nested one appears as `<dir>:<name>`. This meaningfully changes how team monorepos can scope skills per package. <https://code.claude.com/docs/en/whats-new/2026-w25>

## Changelog items that affect plugins / skills

- **v2.1.152 (early May)** — Added `MessageDisplay` hook event (transforms/hides assistant message text at display time — outsized effect on UX and privacy tooling); `/reload-skills` command; `SessionStart` hooks may return `reloadSkills: true`; skills and slash commands can set `disallowed-tools` in frontmatter to strip tools while active; new `pluginSuggestionMarketplaces` managed setting. <https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md>
- **v2.1.154 (May 28)** — Plugins may declare `defaultEnabled: false` in `plugin.json` or marketplace entry (install without turning on); `/plugin` Discover tab pins directory-relevant plugins with a "suggested for this directory" label; streaming tool execution always on.
- **v2.1.157 (May 29)** — Plugins in `.claude/skills/` are auto-loaded, no marketplace required; new `claude plugin init <name>` scaffolds a plugin there; autocomplete for `/plugin` subcommands and marketplace names. <https://code.claude.com/docs/en/whats-new/2026-w22>
- **v2.1.163 (June 4)** — `/plugin list --enabled/--disabled` filters; Stop/SubagentStop hooks can return `hookSpecificOutput.additionalContext` to feed guidance back to Claude; malformed SKILL.md loads with empty metadata instead of failing silently.
- **v2.1.166 (June 6)** — `fallbackModel` setting supports up to three fallbacks in order.
- **v2.1.169 (June 8)** — New `post-session` lifecycle hook (runs after session ends, before workspace deletion); `--safe-mode` flag / `CLAUDE_CODE_SAFE_MODE` disables all customizations (CLAUDE.md, plugins, skills, hooks, MCP) — useful for debugging; new `disableBundledSkills` setting (opts out of `/dataviz`, `/code-review`, etc.); skill hot-reload only re-announces changed skills.
- **v2.1.172 (June 10)** — `/plugin` gains a search bar when browsing marketplace plugins; sub-agents can spawn sub-agents (up to 5 levels).
- **v2.1.178 (June 15)** — `Tool(param:value)` permission syntax matches tool input params (e.g. `Agent(model:opus)`) with `*` wildcard; nested `.claude/skills/` load with collision namespacing.
- **v2.1.181 (June 17)** — `/config key=value` sets any setting from the prompt, including in `-p` and Remote Control; MCP per-server specs like `mcp__server__*` in subagent `disallowedTools` now honored.
- **v2.1.186 (June 22)** — `claude mcp login <name>` / `claude mcp logout <name>` run OAuth from CLI without `/mcp` menu (also `--no-browser` for SSH); `/plugin` Installed tab gains a Skills section; skill frontmatter now accepts kebab/snake/camelCase interchangeably; malformed YAML frontmatter no longer fails silently. <https://code.claude.com/docs/en/whats-new/2026-w26>
- **v2.1.195 (June 26)** — Hook matchers with hyphenated identifiers (e.g. `code-reviewer`, `mcp__brave-search`) now exact-match, no accidental substring matches; `/plugin` Enable/Disable now works when `plugin.json` name differs from marketplace entry name; project-`.claude/settings.json`-only plugins now require explicit install consent on every loader path (closes an install-drive-by).
- **v2.1.198 (June 30)** — `/dataviz` skill added; subagents now run in the background by default; built-in Explore agent inherits main model (capped at opus); fixed `.claude/rules/` conditional rules not loading via symlinks.
- **v2.1.199 (July 2)** — Stacked slash-skill invocations `/skill-a /skill-b …` now load all leading skills (up to 5), not only the first.
- **v2.1.203 (July 7)** — MCP `roots/list` now includes the session's additional working directories with `notifications/roots/list_changed`; LSP plugins no longer flagged for disuse when serving diagnostics; one failing LSP no longer blocks other plugins' LSPs on the same extension.
- **v2.1.207 (July 11)** — **Security**: `${user_config.*}` in shell-form plugin hook/monitor/MCP-headersHelper commands is now rejected (shell-injection fix) — hooks must use exec form (`args` array) or `$CLAUDE_PLUGIN_OPTION_<KEY>`. Plugin option values (`pluginConfigs`) are **no longer read from project-level `.claude/settings.json`** — only user, `--settings`, and managed settings honored. Both changes may break plugins that assumed prior behavior. <https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md>
