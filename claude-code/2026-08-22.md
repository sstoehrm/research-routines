# Claude Code — 2026-08-22

## Summary

The 2026-07-25 → 2026-08-22 window was dominated by (1) a wave of
**plugin-infrastructure changes for cloud/self-hosted execution**:
`claude self-hosted-runner` for Team/Enterprise plans (v2.1.224,
2026-08-07), an **`archive` plugin source** (zip-over-HTTPS install with
optional SHA-256 pinning), **`command` plugin marketplace sources**
(v2.1.229, 2026-08-12), full **GitLab support** for marketplaces
(v2.1.232, 2026-08-13), and marketplace/catalog **`headersHelper`**
(v2.1.238, 2026-08-20). Cloud-synced plugins now show as
`name@synced` and cannot override local plugins; **claude.ai-synced
skills were hardened** to stop shadowing local commands/MCP prompts and
to sanitize their bodies (v2.1.228 → v2.1.239). (2) **Cross-session
messaging** landed in v2.1.224 (`SendMessage`, `ListAgents`, `@name`
mentions) with **subagent forking on by default** in v2.1.232. (3) Two
new **bundled Anthropic skills / behaviour changes**: a `/design`
research-preview skill that opens editable UI artboards from the CLI
(v2.1.234, 2026-08-17), a built-in **"Concise" output style**
(v2.1.237, 2026-08-19), and — most consequential for context budgets —
**`claude-api` skill's baseline dropped from ~200k to ~25k tokens** by
loading references on demand (v2.1.234). (4) `claude-security`
plugin advanced to **v0.10.2** on 2026-08-21. (5) A **new PreToolUse
security fix** in v2.1.232 stops auto-allow hooks from bypassing
tool restrictions in background subagent tasks — plugins with
`PreToolUse` hooks should re-verify behaviour. (6) In the third-party
world, **Superpowers shipped v6.3.0** (2026-08-12) with harness
expansion (Devin CLI, Hermes) and crossed ~1.01M installs / ~271K
stars; **Caveman** hit ~439K installs / ~99K stars while **Cavekit was
frozen**; **skill-security-scan** (Zavelinski) emerged as the
static pre-install vetting skill in response to hook-carrying skills.
The community marketplace passed **~2,291 plugins** vs. **~284 in the
Anthropic-official** repo (both as of 2026-08-10).

## Skills

### /design (Anthropic-bundled, NEW)

- Added: **v2.1.234, 2026-08-17** (research preview)
- Source: bundled with Claude Code; brings Claude Design's artboard
  workflow into CLI and Desktop, built on Artifacts.
- Announcement: Anthropic-adjacent (ClaudeDevs, TestingCatalog on X);
  writeup: explainx.ai; classmethod.jp release notes.

What it does: `/design <prompt>` returns several editable UI
variants side-by-side on one pan/zoom canvas. User picks one, tweaks
inline (click-to-select, properties panel), then asks Claude to
implement it as real code. Artboard + implementation live in the same
session.

Behaviour: research preview — expect surface changes. Bundled, so on
by default; can be turned off with `disableBundledSkills` /
`CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` (both in place since v2.1.166–176).

### claude-api (Anthropic-bundled, RE-ARCHITECTED)

- Changed: **v2.1.234, 2026-08-17**
- Baseline context cost cut from **~200k+ tokens to ~25k** by moving

v2.1.219, 2026-07-24).

### skill-security-scan (third-party, NEW / notable)

- Source: <https://github.com/Zavelinski/claude-code-skill-security-scan>
- Public page: <https://zavelinski.github.io/claude-code-skills/skill-security-scan.html>
- License: not confirmed in search results — verify before use.
- Install: manual clone into `~/.claude/skills/` or via aggregator
  listings (mcpmarket, shyft, claudemarketplaces).

Purpose: **statically vets a third-party `SKILL.md` plus any hooks
it ships and the `settings.json` merge it would register — BEFORE
you install.** Never executes the target skill. Returns
`ALLOW / REVIEW / BLOCK` with the exact lines to remove.

Why it matters here: the summer's Superpowers / claude-security /
Cavekit wave landed a lot of hook-heavy skills. This is the
community's response to "a skill is untrusted instructions running
with your privileges, and a skill that ships a hook is code that
runs every turn." Complements Anthropic's Enterprise-only skill /
plugin scanning (beta, see below).

Notes / caveats:

- Third-party defensive tool — self-issued verdict, no formal
  certification.
- Confirm license and audit the scanner script itself before wiring
  it into an install pipeline.
