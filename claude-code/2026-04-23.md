# Claude Code — 2026-04-23

## Summary

Claude Code's extensibility story matured in Q1 2026 around three
moves: (1) the official plugin marketplace
(`anthropics/claude-plugins-official`) crossed ~101 plugins, split
~33 Anthropic-built and ~68 partner plugins (GitHub, Playwright,
Supabase, Figma, Vercel, Linear, Sentry, Stripe, Firebase); (2)
skills were redefined as lazy-loaded workflow packages — the skill
name is in context, full instructions load on demand; (3) several
third-party tools hit serious adoption, notably **claude-mem**
(persistent memory, reportedly 46K+ GitHub stars) and **caveman**
(output-compression skill, ~75% output-token reduction). In parallel
the team shipped new first-party skills like **/ultrareview**
(parallel multi-agent cloud review) and **/fewer-permission-prompts**,
plus operational fixes — MCP `_meta["anthropic/maxResultSizeChars"]`
override up to 500K, `disableSkillShellExecution`, git timeout for
marketplace installs raised 30s → 120s, custom npm registries,
auto-install of plugin dependencies, a `/skills` menu that now sorts
by estimated token count (press `t`).

## Plugins

### claude-mem — persistent memory

- Source: <https://github.com/thedotmack/claude-mem>
- Coverage:
  <https://www.augmentcode.com/learn/claude-mem-46k-stars-persistent-memory-claude-code>
- Install: via plugin marketplace / `/plugin`.
- License: see repo.

Hooks into Claude Code's session lifecycle, captures tool usage,
compresses conversations via Claude's agent-SDK, and stores
everything in a local SQLite database with a Chroma vector index.
Future sessions get relevant context injected automatically. Works
across Claude Code, Cursor, Gemini CLI, Windsurf, and OpenClaw
gateways; Linux / macOS / Windows.

Notes: stores full session transcripts locally — review retention
policy if you work on sensitive code. Creates hooks and long-lived
background processes.

### cavekit — blueprint-driven parallel build

- Source: <https://github.com/JuliusBrussee/cavekit>
- Install: marketplace / `/plugin`.

Companion to the caveman skill. Turns natural-language specs into
blueprints, blueprints into parallel build plans, and runs them
with automated validation and cross-model peer review.
Heavy-handed but useful for green-field scaffolding.

## Skills

### /ultrareview (first-party)

- Source: Claude Code changelog; cloud-hosted multi-agent review.

Runs a parallel multi-agent code review of the current branch (or a
GitHub PR) in Anthropic's cloud. User-triggered, billed per run.
Requires a git repository.

### /fewer-permission-prompts (first-party)

- Source: Claude Code changelog.

Scans recent transcripts for frequent read-only Bash and MCP calls,
then proposes a prioritized allowlist for
`.claude/settings.json`. Low-risk quality-of-life improvement.

### caveman — token-compression skill

- Source: <https://github.com/JuliusBrussee/caveman>
- Plugin hub:
  <https://www.claudepluginhub.com/plugins/juliusbrussee-caveman>
- License: see repo.

Forces ultra-compressed output ("caveman speech") — strips articles,
filler, pleasantries — while leaving generated *code* untouched.
Reported ~75% reduction in output tokens across git commits, PR
reviews, and AI replies. Can also compress CLAUDE.md / todos /
preferences into caveman format to save input tokens.

Notes: review the style before shipping commit messages / PR bodies
to external reviewers — brevity can read as terse. Generated code is
unaffected.

### Skill Creator

- Surface: Claude Code skills docs
  (<https://code.claude.com/docs/en/skills>).

Meta-skill that scaffolds new skills and A/B-tests variants. Useful
starting point when turning a repeated internal workflow into a
skill.

### Skills mechanics update

- Docs: <https://code.claude.com/docs/en/skills>
- Coverage:
  <https://www.agensi.io/learn/claude-code-plugins-vs-skills-explained>

Skills are now bundled workflow packages (instructions + scripts +
templates + reference material), loaded lazily: only the skill
*name* stays in context; the full body loads when invoked. This is
why token-count sorting in `/skills` matters.

## Changelog items that affect plugins / skills (Q1–Q2 2026)

- Changelog sources:
  <https://code.claude.com/docs/en/changelog>,
  <https://claudefa.st/blog/guide/changelog>,
  <https://github.com/anthropics/claude-code/releases>,
  <https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md>,
  <https://releasebot.io/updates/anthropic/claude-code>.

- `/skills` menu now supports sorting by estimated token count
  (`t` toggles).
- MCP tool-result size override via
  `_meta["anthropic/maxResultSizeChars"]` up to 500K — large DB
  schemas / log blobs can pass through without truncation.
- `disableSkillShellExecution` setting: disables inline shell exec
  in skills, custom slash commands, and plugin commands. Useful for
  locked-down environments.
- Marketplace: git timeout for installs raised 30s → 120s; custom
  npm registries and version pinning; plugins with `package.json` +
  lockfile now auto-install deps on install/update; auto-update no
  longer leaves the official marketplace broken when a plugin holds
  files open.
- Plugins system surfaced via `/plugin` in the terminal:
  <https://code.claude.com/docs/en/discover-plugins>.
