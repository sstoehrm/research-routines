# Claude Code — 2026-04-24

## Run metadata

- **Date:** 2026-04-24
- **Window covered:** ~Feb 2026 – Apr 2026 (last ~2-3 months).

## TL;DR

The Claude Code plugin ecosystem has moved from early preview to a real marketplace: **anthropics/claude-plugins-official** now lists 100+ plugins across Anthropic, partner, and community entries, and community collections (Composio, VoltAgent's `awesome-agent-skills`, `claude-code-plugins-plus-skills`) run into the thousands. Recent CLI releases (v2.1.69 → v2.1.101) added **Opus 4.6 with 1M context, conditional hooks, MCP OAuth, plugin executables on the Bash PATH**, and dependency-aware plugin installs. On the skill side, Claude Code now ships several bundled skills (`/simplify`, `/loop`, `/claude-api`, `/update-config`, `/review`, `/security-review`, `/init`, `/keybindings-help`, `/fewer-permission-prompts`, `/session-start-hook`) plus the source-available production document skills (pptx / docx / pdf / xlsx). Plugin / skill count aside, the bigger ecosystem shift is that **skills are now cross-tool portable** via VoltAgent's SKILL.md format — the same skill file works in Claude Code, Codex, Gemini CLI, and Cursor.

## Release-note highlights (Feb – Apr 2026)

From [code.claude.com What's New](https://code.claude.com/docs/en/whats-new) and [anthropics/claude-code releases](https://github.com/anthropics/claude-code/releases):

- **Plugin dependency resolution**: `plugin install` now recovers from interrupted installs and honors dependencies declared in `plugin.json`. `/plugin install` lists auto-installed dependencies. Error handling for conflicting/invalid plugin dependencies improved.
- **Plugin executables on Bash PATH**: plugins can ship executables that are automatically available inside the Bash tool.
- **Conditional hooks**: hooks can now be scoped more narrowly to specific tools / events.
- **MCP OAuth**: MCP servers can authenticate via OAuth.
- **`/skills` menu improvements**: sortable by token count (press `t` to toggle).
- **Opus 4.6 with 1M context** in v2.1.x.
- **Cowork plugins + admin controls** launched around Feb 24, 2026.
- **Week 15 (Apr 6–10) early previews**: Ultraplan, Monitor (streams background events for live reaction), `/loop` self-pacing, `/team-onboarding` replayable setup, `/autofix-pr` auto-fixing PRs from CLI, computer-use research preview. *(Release-note dates: high confidence. Feature status may have shifted since the preview.)*

## Skills

### Bundled skills (ship with Claude Code)

Invoke with `/<name>`. Visible via the `/skills` menu (press `t` to sort by token count).

| Skill | Purpose |
|---|---|
| **`/simplify`** | Review changed code for reuse, quality, efficiency; fix issues. |
| **`/loop`** | Run a prompt / slash command on a recurring interval (e.g. `/loop 5m /foo`). |
| **`/claude-api`** | Build / debug / tune Claude API apps; handles SDK migrations and prompt caching. |
| **`/update-config`** | Configure the Claude Code harness via `settings.json` (permissions, hooks, env vars). |
| **`/review`** | Review a pull request. |
| **`/security-review`** | Complete a security review of pending changes on the current branch. |
| **`/init`** | Initialize a `CLAUDE.md` file with codebase documentation. |
| **`/keybindings-help`** | Customize keyboard shortcuts / chord bindings in `~/.claude/keybindings.json`. |
| **`/fewer-permission-prompts`** | Scan transcripts for common read-only Bash / MCP tool calls, then add a prioritized allowlist to project `.claude/settings.json`. |
| **`/session-start-hook`** | Create a SessionStart hook so a project can run tests / linters during web sessions. |

## Ecosystem notes

- **Marketplace aggregation**: ClaudeMarketplaces.com reports ~110k monthly visitors for plugin discovery as of early 2026. *(medium confidence — third-party figure.)*
- **Package manager**: `ccpi` (from `jeremylongshore/claude-code-plugins-plus-skills`) is the first community plugin/skill package manager.
- **Cross-tool skill portability**: VoltAgent's SKILL.md format is explicitly positioned as "works with Claude Code, Codex, Gemini CLI, Cursor" — the biggest format-level change in the skill ecosystem since SKILL.md itself.
- **Plugin vs. skill**: plugins are shareable packages (manifest, namespaced slash commands, distribution via marketplaces); skills are instruction files with optional supporting files (auto-invoked when relevant or invoked explicitly).
