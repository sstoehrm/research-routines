# Claude Code — 2026-05-30

## Summary

Between 2026-04-23 and 2026-05-30 Anthropic shipped its first
first-party security plugin (`security-guidance`) on the official
marketplace and published a 12-plugin `claude-for-legal` open-source
suite. Claude Code itself moved from 2.1.119 to 2.1.157, adding heavy
plugin/skill plumbing: `/reload-plugins` and `/reload-skills`, plugin
`defaultEnabled: false`, dependency enforcement with
`claude plugin prune`, `--plugin-url` zip installs, `claude plugin
init`, `claude plugin details/tag/validate`, and auto-loading of
plugins under `.claude/skills/`. Skills gained `disallowed-tools` in
frontmatter, a `skillOverrides` setting (off / user-invocable-only /
name-only), `${CLAUDE_EFFORT}` substitution, and a new `MessageDisplay`
hook event. **Opus 4.8** (released 2026-05-28 with v2.1.154) became
the default model on most plans and is what `security-guidance`
reviews use unless overridden. Community marketplaces continued
growing (claudemarketplaces.com reports 76 marketplaces / 1,197
plugins as of 2026-05-28; tonsofskills.com reports 425 plugins / 2,810
skills).

## Plugins

### security-guidance (Anthropic, first-party)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/security-guidance>
- Marketplace: Anthropic-managed (`claude-plugins-official`)
- Docs: <https://code.claude.com/docs/en/security-guidance>
- Install: `/plugin install security-guidance@claude-plugins-official`
  then `/reload-plugins` (or enable repo-wide via `.claude/settings.json`
  `enabledPlugins`)
- License: repo is Anthropic-managed; treat as Anthropic-licensed (no
  separate OSS license declared in the plugin subdir — **verify before
  redistribution**)
- Released: 2026-05-26 (announced 2026-05-27). Anthropic reported
  >157K installs in the first 24h (self-reported)

What it does / why it matters: three-layer security review built
entirely on hooks.

- `PostToolUse` on `Edit` / `Write` / `NotebookEdit`: deterministic
  per-edit regex scan for ~25 patterns (`eval(`, `new Function`,
  `os.system`, `child_process.exec`, `pickle`,
  `dangerouslySetInnerHTML`, `.innerHTML=`, edits under
  `.github/workflows/`, etc.) — no model call, no token cost.
- `Stop` hook: end-of-turn diff review against a baseline captured at
  `UserPromptSubmit`; background Claude call (default Opus 4.7,
  override with `SECURITY_REVIEW_MODEL`).
- `PostToolUse` on `Bash` filtered to `git commit` / `git push`:
  agentic review using Claude Agent SDK in `~/.claude/security/` venv
  (override with `SG_AGENTIC_MODEL`); capped at 20 reviews per rolling
  hour.
- Anthropic reports 30–40% fewer security comments on internal PRs
  after rollout (self-reported).

Notes / caveats:

- Requires Claude Code ≥ 2.1.144 and Python 3.8+ on `PATH` (tries
  `python3`, `python`, `py -3`).
- `SessionStart` hook creates a venv at `~/.claude/security/` and
  pip-installs `claude-agent-sdk` (needs network on first run); on
  Windows the venv is skipped and the agentic layer falls back to
  single-shot.
- Reads optional project / user rule files:
  `.claude/claude-security-guidance.md`,
  `.claude/security-patterns.yaml|yml|json`. YAML form needs PyYAML.
- Logs to `~/.claude/security/log.txt`.
- Counts toward usage for the model-backed layers (Anthropic API quota).
- Findings are **advisory** — does not block writes or commits.
- Per-edit warning fires once per pattern per file per session
  (rate-limited).
- Disable env vars: `ENABLE_PATTERN_RULES=0`, `ENABLE_STOP_REVIEW=0`,
  `ENABLE_COMMIT_REVIEW=0`, `ENABLE_CODE_SECURITY_REVIEW=0`,
  `SECURITY_GUIDANCE_DISABLE=1`.

### claude-for-legal (Anthropic, first-party suite)

- Source: <https://github.com/anthropics/claude-for-legal>
- Marketplace: repo bundles its own plugin / marketplace manifest;
  install via `/plugin marketplace add anthropics/claude-for-legal`
  then per-plugin install
- License: **Apache 2.0** (commercial use, modification,
  redistribution allowed)
- Released: 2026-05-12 (882 stars / 165 forks in first 24h per
  third-party coverage)

What it does: 12 practice-area plugins (litigation, contracts, IP,
employment, etc.), 80+ specialized agents, ~20 MCP connectors, and a
Managed Agents API reference. Every plugin is a `SKILL.md` file
authored in Markdown so non-developers can read / edit it.

Notes / caveats: outputs are marketed as drafts for attorney review;
not a model release, purely a skills + agents layer on top of Claude
Code.

### claude-mem (community, prior report — update only)

- Source: <https://github.com/thedotmack/claude-mem>
- Install:
  `/plugin marketplace add thedotmack/claude-mem && /plugin install claude-mem@thedotmack`
- License: per repo (MIT historically — verify before adoption)
- Update since 2026-04-23: reached **v12.6.4** by 2026-05-05.
  Continues to hook `SessionStart`, `PostToolUse`, `Stop`,
  `UserPromptSubmit`, `SessionEnd`; now bundles a Chroma vector store
  with local `all-MiniLM-L6-v2` ONNX embeddings (no outbound calls).

Notes / caveats: heavy hook footprint and a SQLite + Chroma store
under the user dir; check disk impact before installing on shared
machines.

## Skills

The skills story this cycle is dominated by mechanics changes (see
Changelog) rather than headline new community skills.

### /code-review (renamed, first-party)

- Source: built into Claude Code (`plugins/code-review` in
  `anthropic/claude-code`)
- Released: renamed from `/simplify` in 2.1.147 (2026-05-21);
  `/simplify` restored as a separate quality-only command in 2.1.135
  (2026-05-07 reversal). Net result: both exist — `/code-review` hunts
  bugs, `/simplify` only does quality cleanups.
- License: Anthropic

What it does: reviews the current diff for correctness, reuse,
simplification, efficiency. New `--fix` flag (shipped 2.1.152,
2026-05-26) applies findings to the working tree directly; `--comment`
posts them as inline PR comments.

Notes / caveats: skill **writes to the working tree** when `--fix` is
used; review effort can be `low` / `medium` / `high` / `max`.

## Changelog items that affect plugins / skills (since 2026-04-23)

Source for all entries: <https://code.claude.com/docs/en/changelog>

### Plugin system

- **2.1.157 (2026-05-29)**: plugins under `.claude/skills/`
  auto-loaded without a marketplace; `claude plugin init <name>`
  scaffolds new plugins; `/plugin` argument autocomplete
  (subcommands, installed names, known marketplaces).
- **2.1.154 (2026-05-28)**: plugins can declare
  `defaultEnabled: false`; `/plugin` Discover tab pins plugins
  matching the cwd ("suggested for this directory"); Opus 4.8 support
  added to the `/claude-api` skill.
- **2.1.152 (2026-05-27)**: `pluginSuggestionMarketplaces` managed
  setting (admins allowlist org marketplaces for context-aware tips).
- **2.1.151 (2026-05-26)**: `/reload-plugins` command.
- **2.1.149 (2026-05-22)**: `/usage` shows per-MCP-server cost
  breakdown.
- **2.1.145 (2026-05-19)**: `/plugin` Discover / Browse shows
  components (commands / agents / skills / hooks / MCP / LSP) before
  install.
- **2.1.144 (2026-05-19)**: `/plugin` browse / discover shows
  last-updated and projected per-turn / per-invocation token cost.
- **2.1.143 (2026-05-15)**: plugin dependency enforcement;
  `claude plugin disable` refuses if another enabled plugin depends
  on it; `claude plugin enable` force-enables transitive deps.
- **2.1.142 (2026-05-14)**: root-level `SKILL.md` (no `skills/`
  subdir) surfaces as a skill; `claude plugin details` includes LSP
  servers.
- **2.1.141 (2026-05-13)**: `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` env var
  to clone plugins over HTTPS instead of SSH.
- **2.1.140 (2026-05-12)**: `claude plugin details <name>` shows
  component inventory and projected token cost.
- **2.1.139 (2026-05-11)**: `defaultEnabled: false` introduced
  (preview); `/context` now shows providing plugin for plugin-sourced
  skills.
- **2.1.136 (2026-05-08)**: `themes` / `monitors` in plugin manifests
  should move under `"experimental"`; `claude plugin validate` warns.
- **2.1.129 (2026-05-06)**: `--plugin-url <url>` flag fetches a plugin
  `.zip` for the current session.
- **2.1.128 (2026-05-04)**: `--plugin-dir` accepts `.zip` archives in
  addition to directories.
- **2.1.127 (2026-05-02)**: `claude plugin prune` removes orphaned
  auto-installed dependencies; `claude plugin uninstall --prune`
  cascades; `skills: ["./"]` now valid.
- **2.1.118 (2026-04-23)**: `claude plugin tag` creates release git
  tags with version validation.

### Skills system

- **2.1.152 (2026-05-27)**: skills & slash commands accept
  `disallowed-tools` in frontmatter to remove tools while active;
  `/reload-skills` command; `SessionStart` hooks can return
  `reloadSkills: true` and set `hookSpecificOutput.sessionTitle`; new
  **`MessageDisplay`** hook event (transforms / hides assistant
  message text as it streams).
- **2.1.133 (2026-05-07)**: `skillOverrides` setting with three modes
  — `off` (hide from model and `/`), `user-invocable-only` (hide from
  model), `name-only` (collapse description).
- **2.1.132 (2026-05-06)**: `/reload-skills` first appears (later
  refined in 2.1.152).
- **2.1.121 (2026-04-28)**: type-to-filter search box in `/skills`;
  `PostToolUse` hooks can replace tool output via
  `hookSpecificOutput.updatedToolOutput`.
- **2.1.120 (2026-04-28)**: skills can reference current effort via
  `${CLAUDE_EFFORT}` substitution.
- **2.1.119 (2026-04-23)**: `/skills` `Enter` pre-fills
  `/<skill-name>` in the prompt instead of closing the dialog; fix
  for skills invoked before auto-compaction being re-executed against
  the next message.

### MCP (affects plugin-shipped MCP servers)

- **2.1.147 (2026-05-21)**: subagent frontmatter MCP servers now
  respect `--strict-mcp-config` and managed policies; blocked
  subagent MCP servers surface visible warnings; stdio MCP
  subprocesses receive `CLAUDE_CODE_SESSION_ID` and `CLAUDECODE=1`;
  `.mcp.json` unapproved servers show `⏸ Pending approval` in
  `claude mcp list`.
- **2.1.145 / 2.1.144 (2026-05-19)**: paginated `tools/list` now
  fully fetched; image MIME handling fixed.
- **2.1.143 (2026-05-15)**: MCP servers with transient errors
  auto-retry up to 3× before staying disconnected.
- **2.1.128 (2026-05-04)**: `workspace` reserved as MCP server name;
  reconnects no longer flood the conversation with full tool lists.
- **2.1.127 (2026-05-02)**: MCP server config gains `alwaysLoad`
  (skip deferral when `true`).
- **2.1.118 (2026-04-23)**: hooks can invoke MCP tools directly via
  `type: "mcp_tool"`.
