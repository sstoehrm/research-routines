# Claude Code — 2026-08-15

## Summary

The July 26 → August 15 window in Claude Code is defined by ecosystem
plumbing, not new headline plugins from Anthropic. The Anthropic-managed
`claude-plugins-official` marketplace added exactly one new plugin
(**superdesign**, third-party, MIT, PR #5185 merged 2026-08-11) and
**removed one** for the first time this year — the upstream-deprecated
`aws-dev-toolkit` (PR #5357, 2026-08-14). Everything else in that repo
during the window is a routine version bump. The bigger story is on the
CLI: **v2.1.221** landed the plugin-marketplace refresh-on-install and
made `/plugin install` activate a plugin in the current session when
safe; **v2.1.224** (2026-08-07) shipped the new **`archive` plugin
source** (zip over HTTPS with optional SHA-256 pin), cross-session
`SendMessage`, self-hosted runners in beta, and JWT- and SigV4-aware
credential masking; **v2.1.228** (2026-08-11) added GitLab support to
plugin marketplaces and friendlier `additionalMarketplaces` /
`allowedMarketplaces` aliases; **v2.1.229** (2026-08-12) added `command`
marketplace sources for IDE-driven plugin resolution and made
server-supplied hooks work in self-hosted runner sessions; **v2.1.232**
patched two Windows permission bypasses (Cygwin symlinks, PowerShell
variable overwrite); and **v2.1.233** (2026-08-14) quietly removed the
Todo/task-tracking tools on Opus 4.8, Sonnet 5, Fable 5 and Mythos 5
(`CLAUDE_CODE_ENABLE_TODO_TOOLS=1` restores them). Third-party movement:
**Superpowers v6.2.0** (Jul 24) and **v6.3.0** (Aug 12) restructured
subagent-driven development and added Devin CLI / Hermes / Grok Build
installers; **Caveman 2.0.0** (Aug 11) shipped a new compression engine
and — importantly — **re-licensed the engine/proxy modules under
BSL-1.1** while keeping the skill and CLI on MIT. Security backdrop:
**Novee Security disclosed CVE-2026-54316 at Black Hat USA on Aug 5**,
a Hugging Face-download-counter exfiltration channel in Claude Code
fixed already in **v2.1.163** (mid-June); the disclosure is retroactive
context for the window rather than a new fix. The **`anthropics/
claude-plugins-community`** marketplace added a normal batch of vetted
entries and — new this window — introduced a **scheduled source-
availability sweep** (PR #2357) that removed 10 entries whose upstreams
were gone.

## Plugins

### superdesign (third-party via official marketplace, NEW)

- Source: <https://github.com/superdesigndev/superdesign-skill>
- Marketplace: `claude-plugins-official`
- Install: `/plugin install superdesign@claude-plugins-official`
- License: **MIT** (per marketplace entry and repo)
- Announced / released: PR #5185 merged 2026-08-11, pinned to
  `dc59c1b1b9661580831f0b6e0eff8e879967d282`.

Reads your codebase for context, sets up a design system, and generates
branchable UI drafts on an infinite canvas — the first design-tool
skill vendor listed as an Anthropic-marketplace plugin (category
`design`). The `npx skills add superdesigndev/superdesign-skill` route
already existed; the new step is the vetted marketplace listing.

Notes / caveats:

- Same folder is used across Claude Code, Cursor, Windsurf, and other
  agentic tools — no Claude Code-specific state.
- Superdesign's own service is a paid product ($20/month flat); the
  skill itself is free.

### aws-dev-toolkit (Anthropic-official, REMOVED)

- Removal: PR #5357 merged 2026-08-14 in `claude-plugins-official`.
- Reason: upstream (`aws-samples/sample-claude-code-plugins-for-startups`)
  marked deprecated; removal was at the maintainer's request.
- Companion PR to `claude-plugins-community` #2367 removes the same
  entry from the community marketplace.

First removal from the Anthropic-managed marketplace this reporting
year. Teams that scripted `/plugin install aws-dev-toolkit@claude-
plugins-official` will now fail; there is **no announced replacement**
— `aws-agents` covers a different scope (Bedrock agent building), so
this is a straight retirement, not a rename.

### Superpowers (third-party, UPDATED)

- Source: <https://github.com/obra/superpowers>
- Marketplaces: `obra/superpowers-marketplace`; also carried as
  `superpowers@claude-plugins-official`.
- License: **MIT** (verified — `LICENSE`, © 2025 Jesse Vincent).
- Versions in window: **v6.2.0 (2026-07-24)** and
  **v6.3.0 (2026-08-12)**.

v6.2.0 restructures Subagent-Driven Development around **plan-scoped
workspaces** (`.superpowers/sdd/<plan-basename>/`) so parallel plans
don't pollute a shared ledger, and replaces fresh-dispatch reviews
with resume-the-implementer semantics plus a five-round circuit
breaker. Windows SessionStart hook now `shell: "bash"` to force Git
Bash and dodge PowerShell / cmd quoting bugs.

v6.3.0 (2026-08-12):

- **Devin CLI, Hermes Agent, Grok Build CLI** installers land —
  `devin plugins install obra/superpowers` now works with auto-trigger
  at session start.
- **Brainstorm workflow classification**: requests bucketed as
  `spike`, `bounded`, or `architectural`; small tasks skip the
  two-document ritual.
- Controllers can rule on non-destructive plan conflicts autonomously.
- Batching of similar micro-tasks; implementers/reviewers stop
  duplicate-spawning subagents.
- **Worktree removal no longer destroys untracked files** — prompts on
  uncommitted work.
- Codex agent waits are now event-driven instead of polling.

Notes / caveats:

- Heavy hook and skill footprint unchanged. Review the SessionStart
  hook and worktree behavior before rolling to a shared repo.
- Third-party — not Anthropic-managed. Still the largest install base
  in the ecosystem.

### Caveman (third-party, UPDATED / re-licensed)

- Source: <https://github.com/JuliusBrussee/caveman>
- License in window: **dual — MIT for skill / CLI / SDKs / evals;
  BSL-1.1 for engine, proxy, cacheengine, rewriter, browse, mcp,
  shrink, cavemem Go core, and shared/platform**. BSL-1.1 converts to
  Apache 2.0 after ~4 years; free self-host, commercial license
  required for resale as a service. Verified from repo `LICENSE`.
- Versions in window: **v1.10.0 (2026-08-03)** and
  **v2.0.0 (2026-08-11)**.

v1.10.0 tightens the token-savings measurement so the reported number
is **net** (subtracts the skill's own ~1–1.5K input-tokens-per-turn
overhead from gross savings). v2.0.0 ships the new **compression
engine** — processes tool outputs, logs, code and JSON before they
reach the model. Demo run: a 40-record JSON blob 16,098 → 1,091 tokens
(93% reduction), reversible.

Notes / caveats:

- The **license split is the story**. Any team embedding Caveman's
  engine into a hosted product needs a commercial BSL license; the
  editing-style skill and CLI stay MIT.
- Community marketplace has already bumped its `caveman` pin to
  `30983423` (PR #2338, 2026-08-11).
- Cavekit (companion nine-skill bundle) had **no release** in the
  window — last tagged v3.1.0, 2026-04-18.

## Changelog items that affect plugins / skills

All from <https://code.claude.com/docs/en/changelog> unless noted.

- **v2.1.220 (2026-07-25)** — Bug fixes and reliability only.
- **v2.1.221 (2026-08-04)** — `/plugin install` refreshes stale
  marketplace catalog and retries before "plugin not found". Plugins
  installed from `/plugin` **activate in the current session when
  safe**, instead of always requiring `/reload-plugins`. Plugins
  accept `"."` as a `skills` path. `/status` shows session kind
  (`interactive`, `attached`, `unattended`). New **VS Code Focus view
  (`Ctrl+Alt+F`)**. New `claude-api` **`/prompt-audit`** subcommand.
  New `mode: "mask"` sandbox credential files (Linux/WSL).
- **v2.1.222 (2026-08-04)** — Worktree isolation now applies to file
  edits **and** Bash in every session type and in subagents.
  PreToolUse auto-allow hooks no longer bypass tool restrictions in
  background summaries / compaction / renames. `SendMessage` before
  dispatch now runs through the permission classifier. **Ultraplan
  feature removed.**
- **v2.1.223 (2026-08-06)** — `strictKnownMarketplaces` and
  `blockedMarketplaces` accept `"owner/*"` wildcards for allowing or
  blocking a whole GitHub org. Bash permission bypass via hidden
  command padding fixed. **Workflow scripts can no longer use
  dynamic `import()`** to escape the workflow sandbox. Agent
  definition `bypassPermissions` now respects org bypass-disable.
  `/review` becomes an alias of `/code-review`.
- **v2.1.224 (2026-08-07)** — **New `archive` plugin source**: install
  plugins from a zip over HTTPS, no git or npm, optional SHA-256 pin.
  **Cross-session `SendMessage`** on macOS / Linux with `ListAgents`
  discovery. `crossSessionInbound` and `dialogExpiry` settings. New
  sandbox credential-masking options: `extract`,
  `onExtractNoMatch`, `decode: "jwt"` with `maskClaims`, and AWS
  SigV4 re-signing (needs `network.tlsTerminate`). Self-hosted
  environments beta (Team / Enterprise). **200-subagent-per-session
  cap removed.**
- **v2.1.225 (2026-08-08)** — Workspace-trust prompt added to
  `claude agents` for untrusted directories. Gateway spend-limit
  surfaced in usage warning.
- **v2.1.226 (2026-08-08)** — Bug fixes only.
- **v2.1.227 (2026-08-10)** — Fixed feature-flag / subscription-tier
  race; minor slash-command menu polish.
- **v2.1.228 (2026-08-11)** — **GitLab plugin marketplace support**:
  bare `gitlab.com` repo URLs (nested subgroups too) clone like
  GitHub URLs. Friendlier aliases: `additionalMarketplaces` /
  `allowedMarketplaces` for `extraKnownMarketplaces` /
  `strictKnownMarketplaces`. `/plugin install plugin@marketplace`
  **refreshes the marketplace first**, so newly published plugins
  install without a manual refresh. `/code-review` at `high`,
  `xhigh`, `max` now runs in a background agent. GitLab token-family
  redaction; PowerShell variable-overwrite permission bypass fix;
  Windows Cygwin-style symlink bypass fix; nested-git-repo trust
  inheritance fix; MCP protocol-version probe hang fix. Bash `<
  file` redirections permission-checked on all platforms.
- **v2.1.229 (2026-08-12)** — **New plugin marketplace `command`
  source**: a local command (e.g. an IDE) prints the plugin
  directory, re-resolved every session, `mode: "link"` uses it in
  place. **Server-supplied hook support for self-hosted runner
  sessions**, matching managed-environment behavior. `/commit-push-pr`
  no longer auto-approves dangerous git/gh flags (`--force`,
  `--amend`, `--no-verify`, etc.). Sandbox: bracketed IPv6 literals,
  ambiguous spellings fail-closed. Dynamic workflows respect
  container CPU limits.
- **v2.1.231 (2026-08-13)** — Single-fix release: MCP OAuth
  redirect-URI mismatch for pre-registered clients (e.g. Slack).
- **v2.1.232 (2026-08-13)** — Superset re-issue of v2.1.228's

  `--settings`** (project settings can no longer override); a
  startup race that could silently unregister a plugin marketplace

- **v2.1.233 (2026-08-14)** — **Todo tools removed by default on Opus
  4.8, Sonnet 5, Fable 5, Mythos 5 and newer**; set
  `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` to keep them. `claude plugin
  validate` checks bare `.claude/skills` directories for parseable
  `SKILL.md` frontmatter. Skill / command argument substitution
  fixed so argument values can't be re-expanded as template markers.
  Bundled skill aliases like `/checkup` and `/review` no longer
  report "Unknown command" in `-p` mode when a user or project skill
  shadows the bundled one. Windows NT `\??\` device-prefix bypass
  closed (NTLM credential-leak vector).

## Leads worth watching (unverified)

- **CVE-2026-54316** — disclosed by Elad Meged (Novee Security) at
  Black Hat USA on 2026-08-05: a public GitHub issue could steer
  Claude Code's WebFetch, pre-approved for `huggingface.co`, to
  exfiltrate an API key one character at a time using Hugging Face's
  public download counter as a covert channel. **Fixed already in
  v2.1.163** (mid-June), so nothing to patch in the window — but the
  Black Hat talk quantified affected range as **0.2.54 → 2.1.163**
  and rated it 9.1 on CVSS v3.1 / 6.0 on CVSS v4. Anthropic's own
  rating: Moderate. Retroactive context.
- **CVE-2026-46406** — `/copy` command insecure temp file
  (`/tmp/claude/response.md`, world-readable, symlink-followable).
  Also pre-window: **fixed in v2.1.128**, published 2026-06-29,
  CVSS 6.1. Included because the NVD entry landed inside the window
  and teams may see it as new.
- **Superpowers v6.3.0** — the Devin CLI / Hermes / Grok Build
  installers imply the same `SKILL.md` chain will run on non-Claude
  agents; how faithfully controllers, plan-scoped workspaces, and
  the review circuit-breaker behave under Devin's session lifecycle
  is untested outside the release notes.
- **claude-plugins-community** — PR #2357 introduced a scheduled
  source-availability sweep; PR #2356 removed 8 entries in one shot.
  Which owner accounts triggered removal, and whether the community
  marketplace will start freezing pins on abandoned repos instead of
  dropping them, is not yet published.
- **Novee / Cloud Security Alliance research note (2026-08-08)** —
  claims the three-round patch-and-bypass at Claude Code touches
  plugin trust surface (hooks, project files). Direct link
  (research.checkpoint.com, thehackernews.com) was egress-blocked
  during this research; secondary summaries only.
- **Anthropic managed-marketplace curation** — the fact that
  **exactly one third-party plugin (superdesign) was accepted this
  window** while community-marketplace accepted a dozen suggests
  Anthropic is actively rate-limiting the official listing. No
  policy statement seen; worth watching next cycle.
- **`archive` plugin source** — the SHA-256 pin is optional per the
  changelog; whether managed enterprise settings can force it to be
  required (analogous to `strictKnownMarketplaces`) is not
  documented yet.
- **`command` plugin marketplace source (v2.1.229)** — IDE-driven
  plugin resolution is a new trust boundary: a compromised IDE
  process now decides which plugin directory ships. No security
  guidance page yet.

  **any plugin's pre-approved WebFetch domain** could become an
  exfiltration side-channel; no plugin-level guidance in this
  window's changelog beyond the specific `huggingface.co` fix.
