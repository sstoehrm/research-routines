# Claude Code — 2026-09-12

## Summary

The July 25 → September 12 window is dominated by (1) a **massive
expansion of `anthropics/claude-plugins-official`** — the marketplace
now lists ~295 plugins (against the handful the prior report tracked),
with ~38 Anthropic-authored ones (all Apache-2.0) and ~14 first-party
external plugins living in-repo under `external_plugins/`; (2) a new
class of Anthropic-authored plugins for **skill and plugin authoring**
(`skill-creator`, `plugin-dev`, `hookify`, `pr-review-toolkit`,
`feature-dev`, `code-modernization`, `ralph-loop`) plus **session
introspection** (`receipts`, `session-report`) and **CLAUDE.md
maintenance** (`claude-md-management`); (3) a full LSP family
(`clangd`, `csharp`, `gopls`, `jdtls`, `kotlin`, `lua`, `php`,
`pyright`, `ruby`, `rust-analyzer`, `swift`, `typescript`) shipped as
individual plugins; (4) **`/design`** landing in v2.1.234 (2026-08-17)
as the first Claude Design skill inside the CLI, joined by the new
**Concise output style** in v2.1.237 and **`/skill-doctor`** in
v2.1.261 (2026-09-04) for auditing per-turn skill-listing cost; and
(5) the introduction of **`claude plugin eval`** in v2.1.269
(2026-09-11) — a full eval harness (six grader types, a no-plugin
baseline, an HTML report, CI-gateable) that makes plugins and skills
testable the way agents are. Superpowers ticked to v6.2.0 (tagged
2026-07-24, verified in-window Aug 12), and Caveman jumped to a v2.x
line (v2.5.0 on 2026-09-02 per third-party trackers) but Cavekit went
into "frozen" maintenance.

## Plugins

### hookify (Anthropic-official, NEW)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/hookify>
- Install: `/plugin install hookify@claude-plugins-official`
- License: Apache-2.0 (per repo LICENSE file)
- Author: Anthropic (`support@anthropic.com`)

Lets a user create custom Claude Code hooks from markdown-with-YAML
rule files instead of hand-editing `hooks.json`. Rules match on event
types `bash`, `file`, `stop`, `prompt`, or `all`, use regex to describe
the unwanted pattern, and choose `warn` (allow with a message) or
`block` (refuse the operation or stop the session). Rule changes are
picked up mid-session — no restart. Commands: `/hookify`,
`/hookify:list`, `/hookify:configure`.

Notes / caveats:

- Because rules can `block` operations, an aggressive `.claude/hookify`
  file can silently stop bash / edit turns — treat it like any other
  hooks source and review before enabling on a shared repo.
- Auto-generation infers rules from conversation patterns; hand-review
  what it writes.

### ralph-loop (Anthropic-official, NEW)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/ralph-loop>
- Install: `/plugin install ralph-loop@claude-plugins-official`
- License: Apache-2.0

Implements the "Ralph Wiggum" iterative technique: `/ralph-loop
"<prompt>" --max-iterations N --completion-promise "<text>"` runs the
same prompt in a loop; a **Stop hook** intercepts each session exit
and re-feeds the prompt, so Claude sees its previous work in the file
tree and git history and keeps iterating until it emits the completion
promise or hits max iterations. `/cancel-ralph` bails out.

Notes / caveats:

- Stop-hook driven — the plugin's entire mechanic is refusing to let
  the session end. Combining with other Stop hooks (e.g.
  `security-guidance`'s end-of-turn diff review) is untested; expect
  interaction.
- Explicit non-goals: production debugging or anything needing human
  judgment mid-loop.
- Token-heavy by design.

### code-modernization (Anthropic-official, NEW)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/code-modernization>
- Install: `/plugin install code-modernization@claude-plugins-official`
- License: Apache-2.0

Long-form legacy-modernisation workflow (COBOL, legacy Java / C++ /
.NET, monolithic web apps). Enforced sequence: `preflight → assess →
map → extract-rules → brief → (reimagine | transform | uplift) →
harden`, with slash commands for each step, and eight specialist
subagents (`legacy-analyst`, `business-rules-extractor`,
`architecture-critic`, `security-auditor`, `test-engineer`,
`version-delta-analyst`, `uplift-migrator`, `scaffolder`).

Notes / caveats:

- Recommends a `.claude/settings.json` `permissions` block that
  **denies** `Edit(legacy/**)` and `Write(legacy/**)` and only permits
  writes to `analysis/**` and `modernized/**`. Flag this: the plugin's
  safety story hinges on those deny rules — don't install it and skip
  the setup step.

### receipts (Anthropic-official, NEW)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/receipts>
- Install: `/plugin install receipts@claude-plugins-official`
- License: Apache-2.0

`/receipts [week|quarter|N|for <repo>]` builds a personal impact
report from local `~/.claude/projects/**/*.jsonl` transcripts:
files touched, lines changed, commits, PRs, per-project usage share.
Emits a markdown report and a self-contained HTML "receipt" (Export
CSV, printable). All processing local — read-only `git` and no code /
conversation content sent to a model; only counts and project names.

### mcp-tunnels (Anthropic-official, NEW — research preview)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/mcp-tunnels>
- Install: `/plugin install mcp-tunnels@claude-plugins-official`
- License: See plugin LICENSE

`/create-docker-mcp-tunnel [dir]` scaffolds an outbound-only Docker
Compose stack (`mcp-proxy` + `cloudflared` + optional `hello-mcp`
FastMCP sample) that lets Claude reach a private-network MCP server
via Anthropic's MCP tunnel infrastructure over Cloudflare. Handles
CA + server cert generation, tunnel token in `.env`, integration
guide for Managed Agents and the Messages API.

Notes / caveats:

- Research preview; no uptime guarantee and depends on Cloudflare as
  a third-party transport.
- Requires Docker, Docker Compose, OpenSSL 1.1.1+, and an outbound
  path to `api.anthropic.com:443` + edge on 7844 TCP/UDP.
- Manages certs and tokens on the user's machine — treat the
  generated files like any other MCP credential store.

### LSP plugin family (Anthropic-official, NEW batch)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins>
- Install: `/plugin install <name>-lsp@claude-plugins-official`
- License: Apache-2.0 (per repo)

Twelve individual LSP plugins ship in-repo — `clangd-lsp`, `csharp-lsp`,
`gopls-lsp`, `jdtls-lsp`, `kotlin-lsp`, `lua-lsp`, `php-lsp`,
`pyright-lsp`, `ruby-lsp`, `rust-analyzer-lsp`, `swift-lsp`,

Notes / caveats:

  changelog for the v2.1.261 fix ensuring rejected `shutdown` params
  don't leave rust-analyzer et al. running.
- Individual LSPs need their own toolchain installed locally (JDK for
  `jdtls-lsp`, .NET SDK for `csharp-lsp`, etc.).

## Skills

### /design (Anthropic-bundled, NEW — v2.1.234, 2026-08-17)

- Docs: <https://code.claude.com/docs/en/whats-new/2026-w34>
- Availability: Pro, Max, Team, Enterprise

Brings Claude Design's artboard workflow into the CLI, built on

### Concise output style (Anthropic-bundled, NEW — v2.1.237)

- Docs:
  <https://code.claude.com/docs/en/output-styles#built-in-output-styles>

New built-in output style. Claude leads with the result and drops
preamble/narration. Error reports, security warnings, and destructive-
action confirmations keep full text. Turn on via `/config` or
`"outputStyle": "Concise"` in `~/.claude/settings.json`. Explanations
still expand fully when asked.

### /skill-doctor (Anthropic-bundled, NEW — v2.1.261, 2026-09-04)

- Docs: <https://code.claude.com/docs/en/changelog#2-1-261>

Reports which loaded skills go unused, their per-turn context cost,
and where to disable them; also lists recently-unused plugins. In
interactive mode it opens the `/plugin` manager's Stats tab; under
`-p` it prints plain text.

Motivation: every skill in the skill-listing is added to context on
every turn whether Claude uses it or not; the listing budget defaults
to ~1% of the model's context window. `/skill-doctor` is meant as the
counter-force to the plugin-marketplace-driven proliferation this
window produced.
