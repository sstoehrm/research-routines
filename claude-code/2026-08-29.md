# Claude Code — 2026-08-29

## Summary

The plugin / skill ecosystem had a busy 5 weeks. Anthropic shipped a
new bundled `/design` skill (research preview, v2.1.233+) that brings
Claude Design's artboard workflow into the CLI and Desktop, and split
the Workflow tool's script reference into its own bundled
`workflow-authoring` skill to shrink prompt tokens. The plugin
marketplace format grew two new source types — `archive` (zip over
HTTPS with SHA-256 pinning, v2.1.224) and `command` (a local process
prints the plugin directory, v2.1.229) — plus `headersHelper`
authentication for private marketplaces and catalog entries
(v2.1.238–241). Cloud sessions can now sync plugins from claude.ai
(`name@synced`, v2.1.239), and a wave of `/reload-plugins`, plugin
cache and skill-loading bugs were fixed. On the security side v2.1.251
(Aug 28) rejects plugin command paths that escape the plugin
directory, v2.1.228 / v2.1.232 hardened skills synced from claude.ai
so they cannot shadow local commands, and v2.1.248 added a
`--restricted` execution mode. On the third-party side, **Superpowers
v6.3.0** (Aug 12) added Devin / Hermes / Grok Build CLI support and a
scaled-down brainstorm ritual. Community traffic also spiked around a
`senior-dev-unbundled` review-style plugin. Independent researcher
Johann Rehberger disclosed a working Auto Mode bypass (Aug 28) using a
poisoned zip and Python-library hijack — directly relevant to any
plugin that unpacks archives.

## Plugins

### `/design` — bundled skill / plugin capability (NEW)

- Source:
  <https://code.claude.com/docs/en/whats-new/2026-w34>
- Also: <https://claude.com/plugins/design>
- Install: bundled — type `/design` in Claude Code v2.1.233+ (CLI or
  Desktop). No install step.
- License: Anthropic-owned (proprietary; ships with Claude Code).
- What it does / why it matters: Publishes a canvas of editable
  artboards to claude.ai as an Artifact; you then pick an artboard
  and ask Claude to implement it. First real integration between
  Claude Code and Claude Design. Available on Pro / Max / Team /
  Enterprise.
- Notes / caveats: Research preview, so surface and behaviour may
  shift. Requires the artifact pipeline — will not work in gateways
  or deployments that block artifact publishing (Bedrock / Vertex /
  Foundry — see the `/design` availability follow-up below).

### Superpowers v6.3.0 (obra/superpowers, UPDATED)

- Source: <https://github.com/obra/superpowers/releases> (v6.3.0,
  2026-08-12)
- Install: `/plugin marketplace add obra/superpowers-marketplace`
  then `/plugin install superpowers@superpowers-marketplace`
- License: MIT
- What it does / why it matters: Adds **Devin CLI**, **Hermes
  Agent**, and **Grok Build CLI** as first-class harnesses (session
  starts auto-inject Superpowers skill triggers, alongside the
  existing Claude Code, Cursor, Gemini CLI, Copilot CLI, Codex and

  record "rulings" on non-catastrophic plan conflicts instead of
  pausing, and small similar tasks are batched. Worktree removal no
  longer destroys untracked files.
- Notes / caveats: Third-party; the marketplace installs 8
  sub-plugins. Sets its own `SessionStart` hook to inject skill
  triggers — review before adopting in shared repos.

### Plugin marketplace format — new source types & auth (CHANGELOG)

- Source: <https://code.claude.com/docs/en/changelog> and
  <https://code.claude.com/docs/en/plugin-marketplaces>
- What it does / why it matters:
  - **`archive` source** (v2.1.224, 2026-08-07): install a plugin
    from a zip over HTTPS, optionally pinned to a SHA-256. No git,
    no npm required — makes locked-down environments simpler.
  - **`command` source** (v2.1.229, 2026-08-12): a local command
    (e.g. an IDE integration) prints the plugin directory,
    re-resolved each session and applied without a restart.
  - **`headersHelper`** on `url` marketplaces and catalog entries
    (v2.1.238–241, 2026-08-20 → 2026-08-23): runs a command that
    mints HTTP headers (short-lived tokens) for catalog and
    same-origin `archive` fetches, so a company can front a private
    marketplace with token auth.
- Notes / caveats: `headersHelper` on catalog entries only runs at
  install / update and Claude shows the command first. Together with
  `archive`, this makes it easier to install plugins from private
  hosts that Claude never verifies for you — supply-chain reviews
  should include a check that only trusted `headersHelper` scripts
  and archive origins are configured.

### Cloud-session plugin sync (`name@synced`, NEW)

- Source: v2.1.239 changelog (2026-08-21) —
  <https://code.claude.com/docs/en/changelog>
- What it does / why it matters: Plugins synced from claude.ai now
  appear locally as `name@synced`, respond to
  `claude plugin enable/disable <name>@synced`, and never override a
  same-named plugin you already installed locally. Meaningful for
  teams that use Cowork alongside local Claude Code.
- Notes / caveats: v2.1.228 and v2.1.232 hardened skills synced from
  claude.ai — they no longer shadow local commands or MCP prompts,
  and their descriptions are sanitized and labelled. Assume synced
  content is untrusted.

## Skills

### `workflow-authoring` — bundled (NEW)

- Source: v2.1.236 changelog (2026-08-19),
  <https://code.claude.com/docs/en/skills>
- Install: bundled with Claude Code; auto-available only when
  [dynamic workflows](https://code.claude.com/docs/en/workflows) are
  enabled.
- License: Anthropic-owned.
- What it does / why it matters: The Workflow tool's per-turn
  script-writing reference was moved out of the main prompt (5.7k
  tokens → ~1k tokens) into this on-demand bundled skill. Big
  net-positive on context budget for teams that use workflows.
- Notes / caveats: Only loaded when a workflow script is being
  authored; will not appear in `/skills` unless dynamic workflows are
  on.

### `/claude-api upgrade` — bundled (NEW capability)

- Source: v2.1.239 changelog (2026-08-21),
  <https://platform.claude.com/docs/en/agents-and-tools/agent-skills/claude-api-skill>
- Install: bundled; run `/claude-api upgrade`.
- License: Anthropic-owned.
- What it does / why it matters: Migrates Python projects from the
  `anthropic` 0.x SDK to 1.x. Complements the existing `/claude-api
  migrate` (model migrations). Practical for teams still on the old
  SDK. The bundled Python reference was also updated to note that
  timeouts use `anthropic.Timeout`, not `httpx.Timeout`.
- Notes / caveats: Python-only for now.

### `/verify` — bundled (behaviour clarified)

- Source: <https://code.claude.com/docs/en/skills>; behaviour tightened
  v2.1.205+ (documented in this window).
- What it does / why it matters: `/verify` records what worked
  (install commands, env vars, launch script) into a project skill
  at `.claude/skills/verify/SKILL.md` (repo root or touched
  package), so later runs / other agents follow the same steps.
- Notes / caveats: **This skill writes files into your repo** —
  commit-worthy but review the diff before you push, and be aware
  it may silently create or overwrite a `SKILL.md` in your project.
  Docs now say Claude edits it only when a run went wrong, not on
  every clean run.

## Changelog items that affect plugins / skills

- **v2.1.251 (2026-08-28)** — Plugin commands declared in a
  marketplace entry can no longer point outside the plugin directory;
  such paths are now rejected with a path-traversal error. Also
  fixed background sessions occasionally starting without any plugin
  skills when another process was refreshing the marketplace.
  <https://code.claude.com/docs/en/changelog>
- **v2.1.248 (2026-08-27)** — Added `--restricted` mode and
  `CLAUDE_CODE_RESTRICTED=1`: removes built-in code-execution tools
  and `WebFetch` unless named in `--tools`; keeps file tools inside
  cwd; refuses `bypassPermissions`; ignores user / project / local
  settings. Also added `CLAUDE_CODE_SKIP_*_AUTH` for MCP servers.
- **v2.1.247 (2026-08-26)** — Fixed `/reload-plugins` reporting 0
  skills for plugins that use `skills/*/SKILL.md`. Fixed hook error
  messages showing literal `${CLAUDE_PLUGIN_ROOT}`. Fixed bundled
  skill aliases like `/checkup` / `/review` reporting
  "Unknown command" in `-p` mode when shadowed. Fixed skill /
  command argument substitution re-expanding argument values as
  template markers. Hardened marketplace against control / invisible
  characters in names.
- **v2.1.246 (2026-08-25)** — Fixed a version-less marketplace's live
  cache directory being deleted on a second-scope install (could
  disrupt a running session). Fixed plugin install failing on a
  `plugin.json` saved with a UTF-8 BOM. Fixed plugin skills doubling
  the `<plugin>:` prefix in the slash menu when frontmatter `name`
  already includes it. Fixed `claude plugin update` failing when
  given a plugin's bare name.
- **v2.1.243 (2026-08-25)** — Fixed MCP tool calls being reported as
  "completed with no output" instead of "interrupted" in headless /
  remote sessions; fixed MCP tool arguments being sent as JSON
  strings when the schema is empty (`{}`). Fixed plugin cache
  creating duplicate SHA-named directories.
- **v2.1.241 (2026-08-23)** — `headersHelper` support extended to
  plugin marketplaces and catalog entries. Fixed plugin dependencies
  with a `marketplace` field never resolving when both plugins are
  loaded together via `--plugin-dir`.
- **v2.1.239 (2026-08-21)** — Added `/claude-api upgrade`.
  Cloud-session plugins from claude.ai show as `name@synced`. Fixed
  marketplace `metadata.pluginRoot` having no effect.
- **v2.1.238 (2026-08-20)** — `headersHelper` first landed on `url`
  marketplaces and catalog entries. MCP `headersHelper` in project
  `.mcp.json` and inline MCP servers in `--add-dir` agent files now
  require the folder-trust dialog to have been accepted.
- **v2.1.236 (2026-08-19)** — Split the Workflow tool's
  script-writing reference into a bundled `workflow-authoring` skill
  (5.7k → ~1k prompt tokens). Added `ANTHROPIC_DEFAULT_MODEL`.
- **v2.1.233 (2026-08-14)** — Improved `claude plugin validate` to
  check a bare `.claude/skills` directory and report `SKILL.md`
  files whose frontmatter fails to parse. Fixed bundled skill
  aliases (`/checkup`, `/review`) reporting "Unknown command" in
  `-p` mode.
- **v2.1.232 (2026-08-13)** — Settings: `additionalMarketplaces` and
  `allowedMarketplaces` now accepted as friendlier aliases for
  `extraKnownMarketplaces` and `strictKnownMarketplaces`. Hardened
  skills synced from claude.ai (labelled, sanitized, no shadowing).
- **v2.1.229 (2026-08-12)** — `command` plugin marketplace source
  added. Fixed `/reload-plugins` keeping the LSP tool after the last
  LSP plugin is disabled.
- **v2.1.228 (2026-08-11)** — Fixed a settings-merge issue where a
  marketplace entry redefined in a higher-precedence settings tier
  could inherit another tier's custom headers. First hardening of
  claude.ai-synced skills against shadowing.
- **v2.1.224 (2026-08-07)** — `archive` plugin source added (zip
  over HTTPS, optional SHA-256 pin, no git / npm needed). Fixed
  plugin install records being silently corrupted when the same
  plugin is installed in multiple projects.
- **`/design` skill launch** (2026-08-17 / 18, requires v2.1.233+) —
  <https://code.claude.com/docs/en/whats-new/2026-w34>
- **Auto Mode bypass PoC** (2026-08-28) — Johann Rehberger
  demonstrated a ~80% reliable bypass using a malicious ZIP plus
  Python library hijacking. Directly relevant to any plugin / skill
  that unpacks user-supplied archives.
  <https://cybernews.com/security/claude-code-auto-mode-malware-vulnerability/>

## Open questions / follow-ups

- **Community skill count inflation** — aggregators are quoting
  2,800–3,500+ community skills and thousands added per week. Numbers
  are self-reported and not verified against the actual
  `anthropics/claude-plugins-community` marketplace (which appears
  far smaller). Worth spot-checking `.claude-plugin/marketplace.json`
  line count next cycle.
- **`senior-dev-unbundled` license** — aggregator listing does not
  state one; confirm before recommending.
- **`headersHelper` audit** — with private marketplaces + `archive` +
  short-lived tokens now supported, an internal-registry compromise
  gets closer to "one bad zip = code execution". Worth a follow-up
  write-up once someone publishes a reference template setup.
- **`/design` availability outside artifact-supported deployments** —
  unclear whether Bedrock / Vertex / Foundry users with the
  "one-time fullscreen renderer offer" (v2.1.248 note) can actually
  use `/design` or whether it silently no-ops.
- **`ccpi` / `tonsofskills`** — still not in an Anthropic-managed
  marketplace; treat any install path outside
  `anthropics/claude-plugins-official` or
  `anthropics/claude-plugins-community` as third-party trust.
- **Hidden telemetry marker "experiment"** from the July report — no
  changelog entry references it explicitly during this window; worth
  checking again next cycle.
- **`/reload-plugins` skill re-injection** — the underlying issue
  (#61485) is that new skills from freshly-installed plugins are not
  always announced to the model mid-session. The August fixes closed
  the "0 skills reported" side but the "model does not see the new
  skill in-turn" side may still be open — verify next cycle.
