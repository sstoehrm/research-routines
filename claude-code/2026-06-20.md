# Claude Code — 2026-06-20

## Summary

Between mid-April and mid-June 2026 the plugin and skill surface area
roughly tripled. The Anthropic-managed marketplace
(`anthropics/claude-plugins-official`) crossed **~287 plugins** (April:
~101), the Anthropic-built share grew to ~29 with a wave of LSP plugins
(`clangd-lsp`, `csharp-lsp`, `gopls-lsp`, `jdtls-lsp`, `kotlin-lsp`,
`lua-lsp`, `php-lsp`, `pyright-lsp`) plus workflow plugins
(`hookify`, `ralph-loop`, `feature-dev`, `frontend-design`,
`pr-review-toolkit`, `mcp-server-dev`, `mcp-tunnels`, `plugin-dev`,
`playground`, `project-artifact`, `learning-output-style`,
`explanatory-output-style`). Skills got first-class **auto-loading
from `.claude/skills/`** (2.1.157), nested-directory loading (2.1.178),
a `/reload-skills` command, `disallowed-tools` frontmatter, and a
`claude plugin init` scaffolder. Headline community items:
**claude-mem** v13.1.0 added a multi-tenant Postgres backend and
relicensed AGPL → Apache-2.0; **caveman** v1.8.x revised its
compression claim from ~75% to a measured **65%**; **Superpowers**
(Jesse Vincent) hit ~177K stars and was admitted to the official
marketplace. Operationally, Anthropic shipped enterprise marketplace
controls (`blockedMarketplaces`, `pluginSuggestionMarketplaces`),
`--safe-mode` to disable all customisations, dynamic `/workflows`
orchestration on Opus 4.8, and a searchable `/plugin` browser.

## Plugins

### Superpowers (now official-marketplace)

- Source: <https://github.com/obra/superpowers>; listing
  <https://www.claudepluginhub.com/plugins/obra-superpowers-2>
- Install: `/plugin install superpowers@claude-plugins-official` (also
  installable from the obra GitHub source directly).
- License: MIT (per repo).
- What it does / why it matters: Ships an opinionated engineering
  culture as a folder of markdown skills — plan-before-edit,
  tests-before-implementation, two-stage self-review. The same skill
  folder runs across Claude Code, Cursor, OpenAI Codex CLI, GitHub
  Copilot CLI, Gemini CLI, and OpenCode. Per Anthropic's public
  install counter it was #2 by installs as of 2026-06-01 (752,120
  installs vs. `frontend-design` at 829,316).
- Notes / caveats: Installs many SKILL.md files and adds **Stop /
  SubagentStop hooks**; expect the `/skills` listing to grow
  noticeably (sort by `t` to see token cost). Independent reviewers
  note it can over-enforce TDD on throwaway scripts.

### frontend-design (Anthropic)

- Source:
  <https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design>
- Install: `/plugin install frontend-design@claude-plugins-official`.
- License: Apache-2.0.
- What it does / why it matters: A ~50-line SKILL.md that forces a
  four-question framework (purpose, tone, constraints, differentiation)
  and supports React/Vue/Svelte/vanilla output. ~300K installs by late
  April; now the most-installed plugin in the official directory.
- Notes / caveats: Pure-prompt skill, no hooks, no shell exec — safe
  under `disableSkillShellExecution`. The tone presets (brutalist, art
  deco, etc.) are opinions, not constraints — review output before
  shipping to clients.

### feature-dev, ralph-loop, hookify, pr-review-toolkit (Anthropic)

- Source: <https://github.com/anthropics/claude-plugins-official>;
  reference
  <https://deepwiki.com/anthropics/claude-plugins-official/7.5-workflow-and-utility-plugins>
- Install: `/plugin install <name>@claude-plugins-official`.
- License: Apache-2.0.
- What they do:
  - `feature-dev` orchestrates a feature lifecycle (spec → impl →
    review).
  - `ralph-loop` packages Geoffrey Huntley's "Ralph Wiggum"
    technique — a Stop-hook bash loop that keeps Claude running
    until a completion criterion is met (similar surface to `/goal`,
    see Changelog).
  - `hookify` lets users write hook rules as markdown in
    `.claude/hookify.*.local.md` and exposes `/hookify`,
    `/hookify:list`, `/hookify:configure`.
  - `pr-review-toolkit` consolidates the prior `code-review` agents.
- Notes / caveats: `ralph-loop` and `hookify` add Stop / SubagentStop
  hooks — review the markdown rules before enabling, and note that
  `hookify` writes user-scoped local files. **Flag: all of these
  touch hooks / settings.json behaviour by design.**

### LSP plugin family (Anthropic)

- Source: <https://github.com/anthropics/claude-plugins-official>
  (`clangd-lsp`, `csharp-lsp`, `gopls-lsp`, `jdtls-lsp`, `kotlin-lsp`,
  `lua-lsp`, `php-lsp`, `pyright-lsp`)
- Install: `/plugin install <lang>-lsp@claude-plugins-official`.
- License: Apache-2.0 (wrappers); each bundles or fetches the
  upstream LSP under its own license.
- What it does / why it matters: First-party language-server wrappers
  give Claude jump-to-def, references, diagnostics, and rename
  inside-edit. They are the foundation for `/plugin details <name>`
  now also showing LSP servers (2.1.142).
- Notes / caveats: Each plugin runs a stdio LSP binary — counts as
  an additional process per project. `claude --safe-mode` (2.1.169)
  disables them.

### Prismatic Skills for Claude Code

- Source: <https://github.com/prismatic-io/prismatic-skills-claude-code>;
  announcement
  <https://prismatic.io/blog/introducing-prismatic-skills-for-claude-code/>
- Install: third-party; clone repo then `/plugin marketplace add`
  against the local path, or use Prismatic's published marketplace

- License: MIT (open source per launch announcement).
- What it does / why it matters: Turns Claude into a
  Prismatic-platform integration specialist — scaffolds connectors,
  deploys to a Prismatic environment, runs tests, iterates on
  failures. Notable because a partner picked **skills**, not an MCP
  server, as the primary surface — a pattern other SaaS vendors are

  HuggingFace `huggingface-skills`, Liquid/Shopify `liquid-skills`,
  Netlify `netlify-skills`, NVIDIA `nvidia-skills`, Qt, Qdrant,
  Forge, Duende).
- Notes / caveats: Free for all Prismatic customers; talks to
  Prismatic's API — review credentials and network egress in
  restricted environments.

### claude-mem v13.1.0 (persistent memory — major update)

- Source: <https://github.com/thedotmack/claude-mem>; coverage
  <https://www.augmentcode.com/learn/claude-mem-65k-stars>
- Install: `npx claude-mem install` (also installable as a Claude
  Code plugin via the project's marketplace).
- License: **Apache-2.0** (changed from AGPL-3.0 in v13.1.0,
  2026-05-11).
- What it does / why it matters: Records tool-usage observations,
  generates semantic summaries, stores them locally (SQLite + Chroma)
  or — new in v13.1.0 — in a shared **Postgres + BullMQ + Docker
  Compose** backend with tenant isolation, API-key scoping, and
  audit trails. Now ~65–82K stars across coverage outlets. Works
  across Claude Code, Gemini CLI, OpenCode.
- Notes / caveats: Hooks into session lifecycle and runs background
  workers. The server-beta runtime is opt-in; default install is
  still local SQLite. Relicensing to Apache-2.0 removes the AGPL
  friction enterprise users complained about in April. **Flag:**
  modifies hooks; with the server runtime, sends compressed session
  content over the network — review tenancy and retention before
  enabling.

### caveman / cavekit / cavemem

- Source: <https://github.com/JuliusBrussee/caveman>; aggregator
  <https://www.claudepluginhub.com/plugins/juliusbrussee-caveman>
- Install: `/plugin install caveman` from the project's marketplace
  (or via `claudedirectory.org`).
- License: see repo (MIT-style per project README, unchanged).
- What it does / why it matters: Same output-compression idea as
  April — strip articles / pleasantries, leave code untouched — but
  the project's own benchmark suite (10 tasks, v1.8.2) now reports
  **65% mean output-token reduction**, not the 75% headline
  previously circulated. `cavemem` is a new spin-off that
  periodically rewrites CLAUDE.md / project notes in compressed
  form; `cavekit` continues as the blueprint-driven build wrapper.
  Since v1.8.0 (2026-05-10), OpenClaw gets a native skill drop and
  OpenCode gets a native plugin at
  `~/.config/opencode/plugins/caveman/` (no `npx` shim).
- Notes / caveats: Cross-check the 65% number on your own
  representative session. Caveman speech reads as terse to humans —
  review commit messages / PR bodies before sending externally.
  **Flag: `cavemem` rewrites CLAUDE.md.**

## Skills

### /fewer-permission-prompts (first-party, bundled)

- Source: Anthropic, bundled with Claude Code; launch tweet
  <https://x.com/bcherny/status/2044847851591856461>.
- Install: shipped in the CLI; invoke `/fewer-permission-prompts`.
- License: Apache-2.0 (bundled).
- What it does / why it matters: Unchanged in intent from April —
  scans recent transcripts for frequently-approved read-only bash
  and MCP calls, proposes a prioritised allowlist for
  `.claude/settings.json`. **Open bug** filed in early June: drops
  commands prefixed with environment-variable assignments
  (Issue #51057) — review proposed entries before applying.
- Notes / caveats: **Flag: modifies `.claude/settings.json`** (with
  a confirm step). The new `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS`
  env var (2.1.169) hides it.

### /ultrareview (first-party, cloud-hosted)

- Source: changelog entries 2.1.130-series; usage prompt embedded
  in Claude Code.
- Install: bundled; `/ultrareview` for current branch,
  `/ultrareview <PR#>` for a specific PR.
- License: Anthropic-hosted service, not OSS.
- What it does / why it matters: Same parallel multi-agent review
  as April; **Pro/Max free-allotment-of-three expired 2026-05-05**,
  so it's now paid usage. The April open question about a
  local-agent equivalent is partially answered: `/code-review`
  (formerly `/simplify`, renamed in 2.1.147; behaviour changed in
  2.1.152 to accept `--fix` and apply findings to working tree) is
  the local equivalent for cleanups; full adversarial parallel-cloud
  review still requires `/ultrareview`.
- Notes / caveats: Network-dependent. Use `/code-review --fix`
  locally for cheap iterations, reserve `/ultrareview` for
  pre-merge.

### /code-review (renamed local skill)

- Source: Anthropic, bundled.
- Install: `/code-review` (was `/simplify`; renamed in 2.1.147,
  behaviour expanded in 2.1.152).
- License: Apache-2.0 (bundled).
- What it does / why it matters: Runs a cleanup-only review of
  pending changes; with `--fix`, applies findings to the working
  tree. Distinct from `/ultrareview` in that it is local and focused
  on quality (reuse / simplification / efficiency), not adversarial
  bug-hunting.
- Notes / caveats: `--fix` writes files; review the diff before
  committing.

### /deep-research (bundled workflow)

- Source: Anthropic, bundled (shipped alongside dynamic workflows
  in 2.1.154 / Opus 4.8).
- Install: `/deep-research <question>` once on a version that
  supports dynamic workflows.
- License: Apache-2.0 (bundled).
- What it does / why it matters: First bundled "workflow" (vs.
  skill) — fans out parallel web searches, cross-checks sources,
  returns a cited report. Backed by the new dynamic-workflows
  runtime: Claude writes a JS orchestration script and a separate
  runtime spins up subagents.
- Notes / caveats: Requires Opus 4.8 (or fallback). Hits the network
  heavily; can run for minutes. Each workflow run shows in
  `/workflows` with agent counts and tokens; you can pause (`p`),
  kill an agent (`x`), restart (`r`), or save the script as a
  reusable command (`s`).

### Auto-loaded local skills (mechanism change)

- Source: changelog 2.1.157
  <https://www.aibuilderclub.com/blog/claude-code-auto-load-skills-v2157>;
  2.1.178.
- Install: drop a `SKILL.md` (or directory with `SKILL.md`) into
  `.claude/skills/` — no marketplace required. Nested
  `.claude/skills` directories under subprojects load when working
  there; on name clash, the nested skill appears as `<dir>:<name>`.
- License: project-defined.
- What it does / why it matters: Lowers the bar for ad-hoc skills
  from "publish a plugin" to "commit a markdown file". `claude
  plugin init <name>` (2.1.157) scaffolds one. `/reload-skills`
  (2.1.152) re-scans without restart; SessionStart hooks can return
  `reloadSkills: true` to make installed skills available in the
  same session.
- Notes / caveats: Skills can declare `disallowed-tools` in
  frontmatter (2.1.152) to remove tools from Claude's pool while
  the skill is active — a real least-privilege primitive. `\$`
  escape (2.1.163) lets command bodies include a literal `$`
  before a digit. **Flag: dropping a SKILL.md into a shared repo
  means every user of that repo runs that skill — review SKILL.md
  changes in code review.**

## Open questions / follow-ups

- **Caveman 65% vs 75%:** the project's own benchmark revised the
  headline from 75% (April marketing) to a measured 65% on 10 tasks.
  Reproduce on a representative coding session (not a benchmark
  suite) and report a real percentile distribution.
- **claude-mem vs filesystem-memory baseline (still open):** v13.1.0's
  Postgres tenancy changes the deployment story but the question — is
  the SQLite + Chroma vector store actually better than a flat-file
  CLAUDE.md regenerated each session? — is still unanswered. The
  Apache-2.0 relicense makes a head-to-head benchmark easier to
  publish.
- **Anthropic-built vs partner ratio:** ~10% Anthropic / ~85% partner
  / ~3% community-tagged in June (vs ~33% / 67% in April). The
  denominator nearly tripled while Anthropic's absolute output also
  grew — track whether the partner ratio keeps climbing as more
  vertical SaaS vendors ship skills.
- **Local equivalent of `/ultrareview`:** partially answered
  (`/code-review --fix` is the local cleanup analogue) but full
  adversarial parallel-cloud review remains cloud-only. Watch for a
  `/workflows`-based community recipe.
- **`disableSkillShellExecution` adoption:** still no published list
  of which partner plugins are safe under it vs which need shell
  exec. The 287-plugin scale makes this hard; a community audit (or
  a `claude plugin details` flag) would be useful.
- **Skill auto-loading and trust:** with `.claude/skills/`
  auto-loading in nested directories, a committed SKILL.md is
  effectively executable behaviour for every collaborator. Open
  question: do code-review tools (CodeRabbit, GitHub Copilot review)
  flag SKILL.md changes the way they flag dependency bumps?
- **Plugin install-count signal quality:** Anthropic exposed install
  counts (`frontend-design` 829K, `superpowers` 752K, `context7`
  348K). Useful as a coarse popularity proxy but not a quality
  signal — track whether Anthropic adds reviews, version pins, or
  signature verification next.
