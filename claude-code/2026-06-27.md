# Claude Code — 2026-06-27

## Summary

Between late April and June 2026 the Claude Code plugin / skill
ecosystem matured rapidly. The most significant shift is **plugin
development becoming dead-simple**: as of v2.1.157 (May 29), any
`.claude/skills` directory is auto-loaded as a plugin, and
`claude plugin init <name>` scaffolds a working plugin in seconds
(no marketplace round-trip). The official
`anthropics/claude-plugins-official` directory has grown to ~211
plugins (from ~55 in early May), with a flood of vendor-published
bundles (Adobe, Airtable, Airwallex, Apollo, Atlassian, Auth0, AWS,
Azure, Google, Salesforce, Microsoft, Snyk, Aikido, 42Crunch).
Anthropic also shipped **dynamic workflows** (v2.1.154, May 28), the
**MessageDisplay** hook (v2.1.152, May 27), a **post-session**
lifecycle hook and **`--safe-mode`** flag (v2.1.169, June 8), the
**`/cd`** command, the **`disableBundledSkills`** setting, and a
**`/reload-skills`** command. Enterprise governance gained
`pluginSuggestionMarketplaces`, `blockedMarketplaces`,
`requiredMinimumVersion` / `requiredMaximumVersion`, and
`enforceAvailableModels`. `obra/superpowers` was admitted to the
official marketplace and crossed 240k stars.

## Plugins

### superpowers (obra/superpowers)

- Source: <https://github.com/obra/superpowers> (skills now split
  into <https://github.com/obra/superpowers-skills>)
- Install: `/plugin install superpowers@claude-plugins-official`
  (now in Anthropic's official marketplace)
- License: MIT
- What it does / why it matters: An "agentic skills framework +
  software development methodology" — forces Claude through a
  5-phase loop (clarify → design → plan → code → verify), enforces
  TDD red-green-refactor, four-phase root-cause debugging, Socratic
  brainstorming, and subagent-driven code review. Most-installed
  third-party Claude Code plugin; recently re-architected as a thin
  shim that clones a separately versioned skills repo so skills
  update independently of the plugin.
- Notes / caveats: Heavy on token use because every task fans out
  through subagents and discipline phases. Does not write to
  `CLAUDE.md` or `settings.json`. Adds many slash commands and
  skills; review before enabling on small / cheap tasks.

### code-simplifier (Anthropic)

- Source:
  <https://github.com/anthropics/claude-plugins-official/tree/main/plugins/code-simplifier>
- Install: `/plugin install code-simplifier@claude-plugins-official`
- License: Apache-2.0 (per the official marketplace repo)
- What it does / why it matters: Anthropic's own internal cleanup
  pass, released publicly. Runs over recently modified code to
  remove duplication, flatten nesting, clarify expressions — with a
  hard contract that behavior may not change. Pairs with the
  renamed `/code-review` slash command (was `/simplify`, renamed in
  v2.1.147 / v2.1.152).
- Notes / caveats: First-party plugin, no unusual permissions.
  Consumes additional tokens reprocessing already-generated code;
  run selectively. Follows project conventions in `CLAUDE.md` but
  does not modify it.

### firecrawl

- Source: <https://github.com/firecrawl/firecrawl-claude-plugin>
- Install: `/plugin install firecrawl@claude-plugins-official`
- License: MIT
- What it does / why it matters: Adds `/firecrawl:scrape`,
  `/firecrawl:crawl`, `/firecrawl:search` slash commands plus an
  MCP server for clean web extraction. Closes the gap left by
  Claude Code's built-in `WebFetch`, which is brittle on JS-heavy
  and authenticated pages.
- Notes / caveats: Requires a Firecrawl API key (free tier
  available); bundles an MCP server, so it inherits the standard
  MCP permission consent flow.

### adobe-for-creativity (Adobe)

- Source: <https://github.com/adobe/skills>
  (path: `plugins/creative-cloud/adobe-for-creativity`)
- Install:
  `/plugin install adobe-for-creativity@claude-plugins-official`
- License: Apache-2.0 (on `adobe/skills` repo top-level)
- What it does / why it matters: First-party Adobe bundle exposing
  ~50 Photoshop, Firefly, Express, and Premiere tools as Claude
  tools / skills. Notable as one of the earliest large vendor
  creative bundles (April 28 GA) and a model for how vendors are
  now shipping multi-tool plugins instead of bare MCP servers.
- Notes / caveats: Some tools require Adobe sign-in; ~40 tools work
  for guest users. Connector-style auth flow.

### snyk (Secure at Inception)

- Source: <https://github.com/snyk/claude-plugin-snyk>
- Install: `/plugin install snyk@claude-plugins-official`
- License: Per Snyk repo (verify in repo; permissive)
- What it does / why it matters: Snyk vulnerability scanning into
  Claude's edit loop via a `/snyk-fix` directive, validating
  AI-generated code at inception across SAST, SCA, containers, and
  IaC before merge. Representative of the "guardrails-in-loop"
  security category that took off in late May.
- Notes / caveats: Requires Snyk account / auth; runs scans as part
  of the agent loop, increasing latency and token use per edit
  cycle.

### aikido (AikidoSec)

- Source: <https://github.com/AikidoSec/aikido-claude-plugin>
- Install: `/plugin install aikido@claude-plugins-official`
- License: Per AikidoSec repo (verify; appears permissive)
- What it does / why it matters: Companion / alternative to Snyk —
  SAST, secret-detection, and IaC scanning via the Aikido MCP
  server with real-time feedback.
- Notes / caveats: Bundles an MCP server; requires Aikido account.

### 42crunch-api-security-testing

- Source: <https://github.com/42Crunch-AI/claude-plugins>
  (path: `plugins/api-security-testing`, pinned at v1.5.5)
- Install:
  `/plugin install 42crunch-api-security-testing@claude-plugins-official`
- License: Per 42Crunch repo
- What it does / why it matters: Closes the OWASP API Security
  loop (BOLA / BFLA etc.) by automating audit → scan → remediate →
  validate against OpenAPI specs from inside Claude Code.
- Notes / caveats: 42Crunch account required; uses pinned
  `ref` / `sha` in the marketplace entry (good supply-chain
  hygiene).

### airwallex-agentos (Airwallex)

- Source: <https://github.com/airwallex/airwallex-marketplace>
  (path: `plugins/airwallex-agentos`)
- Install:
  `/plugin install airwallex-agentos@claude-plugins-official`
- License: Per Airwallex repo
- What it does / why it matters: Plain-language treasury and AP —
  issue invoices from POs, onboard suppliers from invoices, check
  multi-currency cash. One of the first finance vendor "AgentOS"
  bundles combining pre-built skills with an MCP server and CLI.
- Notes / caveats: Financial-data permissions; production use
  requires Airwallex credentials.

## Skills

### MessageDisplay hook (built-in capability)

- Source: Anthropic changelog v2.1.152 (2026-05-27);
  <https://code.claude.com/docs/en/hooks>
- Install: Built into Claude Code 2.1.152+; configure via
  `settings.json` hooks block
- License: N/A (Claude Code feature)
- What it does / why it matters: Lets a plugin / skill intercept
  and transform or hide assistant-rendered text before display —
  enables PII redaction skills, custom formatting, suppressing
  chain-of-thought leakage, and tone enforcement. Unlocks a class
  of skills that previously required wrapping Claude Code from
  outside.
- Notes / caveats: This **modifies `settings.json`**. Any skill
  shipping a MessageDisplay hook is effectively rewriting model
  output mid-stream; review carefully and audit logs to confirm
  nothing important is being hidden.

### Auto-loaded skills directory (`.claude/skills/*`)

- Source: Changelog v2.1.157 (2026-05-29)
- Install: Drop a `SKILL.md` under `~/.claude/skills/<name>/` or
  run `claude plugin init <name>` to scaffold
- License: N/A (CLI feature)
- What it does / why it matters: Removes the marketplace step
  entirely for personal skills — anything in `.claude/skills`
  loads as `<name>@skills-dir` on next session. Combined with
  `claude plugin init`, this is the lowest-friction path to a
  working skill yet shipped.
- Notes / caveats: Loaded skills can register slash commands,
  hooks, agents, and MCP servers. **Modifies what's in scope
  automatically** — be careful what you drop into
  `~/.claude/skills` and consider `disableBundledSkills` if you
  need to isolate.

### `/reload-skills` and SessionStart `reloadSkills: true`

- Source: Changelog v2.1.152 (2026-05-27)
- Install: Built in; SessionStart hook can opt-in via
  `hookSpecificOutput.reloadSkills: true`
- License: N/A
- What it does / why it matters: First-class hot-reload for skill
  authors — edit `SKILL.md`, run `/reload-skills`, and the change
  is live without restarting the session. The SessionStart trigger
  lets repo-level hooks force a rescan on every fresh session.
- Notes / caveats: A SessionStart hook returning
  `reloadSkills: true` will silently re-scan every session, which
  can be surprising if a teammate is debugging skill resolution.

### apollo-skills (Apollo GraphQL)

- Source: <https://github.com/apollographql/skills>
- Install: `/plugin install apollo-skills@claude-plugins-official`
- License: Per Apollo repo
- What it does / why it matters: 24-skill pack covering Apollo
  Client, Server, Federation, Connectors, Router, Rover CLI, iOS,
  Kotlin, and the Apollo MCP server — schema design, query
  optimization, and GraphQL best practices. Good example of the
  "vendor ships a comprehensive skill library, not just one tool"
  pattern.
- Notes / caveats: Skill-only bundle (no MCP auth flow); large
  skill count may inflate the `/skills` list and affect
  autocomplete latency.

## Open questions / follow-ups

- Verify exact licenses for `snyk`, `aikido`,
  `42crunch-api-security-testing`, `airwallex-agentos`,
  `adobe-for-creativity`, and `apollo-skills` repos — the
  marketplace pins commits but doesn't surface license metadata;
  some are vendor-owned and may have non-standard terms.
- The `claude-plugins-official` marketplace.json declared
  `"strictKnownMarketplaces": []` issue (#34873) blocked the
  official marketplace itself in some configs — status of fix
  unclear; matters for enterprises adopting `blockedMarketplaces`.
- Bundled vs. external `code-simplifier`: there are at least three
  skills / plugins named `code-simplifier` (Anthropic official,
  `getsentry/skills`, `nicknisi/claude-plugins`) — collision
  behavior when multiple are enabled is worth testing.
- `MessageDisplay` hook semantics around tool-call streaming and
  partial messages are documented thinly; would benefit from a
  worked example before recommending broad use.
- Anthropic has not (publicly) shipped a signing / attestation
  story for marketplace plugins beyond pinned SHAs — supply-chain
  risk remains the open question for enterprise rollout.
