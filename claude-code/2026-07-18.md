# Claude Code — 2026-07-18

## Summary

The three months since 2026-04-23 were the most active period yet for
Claude Code's extensibility layer. Two structural shifts dominate:

- **The official plugin marketplace went from soft-launched to a
  first-class system** — `anthropics/claude-plugins-official` publicly
  launched 2026-05-22 with ~55 plugins and now lists roughly 200+ by
  mid-July.
- **Skills became loadable without a marketplace** (v2.1.157,
  2026-05-29): dropping a folder with a `SKILL.md` (or
  `.claude-plugin/plugin.json`) into `.claude/skills/` auto-loads it as
  `<name>@skills-dir`, and `claude plugin init` scaffolds one.
  Nested-directory skill loading (v2.1.178) and a Skills section in
  `/plugin` (v2.1.186) followed.

Alongside those, Anthropic shipped a new first-party **`/dataviz`**
skill (v2.1.198), the largest community skill of the year
(Karpathy `CLAUDE.md`, ~194K stars) matured into a real plugin, and
**`claude-opus-4-8`** with "dynamic workflows" (2026-05-28) reset the
ceiling on multi-agent runs that use skills.

Note: `disableSkillShellExecution` and MCP `anthropic/maxResultSizeChars`
actually landed in v2.1.91 (2026-04-02), which sits **before** this
window's start; they were captured in the previous report and are
included in the changelog section below only as reference.

## Plugins

The official marketplace grew by well over 100 entries in this window
(many enterprise / vendor partner integrations — AWS, Azure, GCP,
CockroachDB, ClickHouse, Convex, CodeRabbit, Auth0, Atlassian,
Airtable, Amplitude, Apollo, Box, Buildkite, Canva, Cloudflare,
Cloudinary, Circle, CrowdStrike, etc.). Rather than enumerate all of
them, this section pulls the ones with the most traction or a novel
primitive.

### `dataviz` skill (bundled — v2.1.198)

- Source: ships bundled in Claude Code 2.1.198+ (2026-07-01) — not a
  separate repo.
- Install: no install. `/dataviz` loads on demand when a chart /
  dashboard / plot task is detected. Bundle can be suppressed with
  `disableBundledSkills` (v2.1.169).
- License: Anthropic-bundled (proprietary, ships with Claude Code).
- What it does / why it matters: loads chart / dashboard design
  guidance into context (chart-type selection, layout, color) plus a
  runnable color-palette validator so Claude verifies its own palette
  against contrast rules before producing SVG / React / matplotlib
  output.
- Notes / caveats: bundled skill — no permissions surface beyond
  normal file I/O. Announcement:
  [Daniel San on X (2026-07-01)](https://x.com/dani_avila7/status/2072460033896419478).

### `frontend-design` (Anthropic, official marketplace)

- Source:
  <https://github.com/anthropics/claude-plugins-official>, subdir
  `plugins/frontend-design`
  ([SKILL.md](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md)).
- Install: `/plugin install frontend-design@claude-plugins-official`.

  avoiding template-looking UIs. Community reports it as the
  highest-install design skill in the ecosystem.
- Notes / caveats: first-party, low-risk. Anthropic-managed
  marketplace.

### `code-review`, `security-guidance`, `pr-review-toolkit` (Anthropic, first-party)

- Source: <https://github.com/anthropics/claude-plugins-official>,
  subdirs under `plugins/`.
- Install: `/plugin install code-review@claude-plugins-official`
  (and equivalents).
- License: MIT.
- What it does / why it matters: `code-review` runs multi-agent
  reviews of a diff for correctness + reuse / simplification (also
  exposed as `/code-review`); `security-guidance` scans diffs for
  injection / XSS / SSRF / exposed-secret / IDOR / auth-bypass;
  `pr-review-toolkit` bundles PR-focused helpers. Docs:
  <https://code.claude.com/docs/en/code-review>. v2.1.203 (2026-07-07)
  improved findings quality specifically on `claude-opus-4-8`.
- Notes / caveats: first-party. `/review <pr>` is now backed by the
  same engine at `medium` effort (v2.1.186).

### `ralph-loop` (Anthropic, first-party)

- Source: <https://github.com/anthropics/claude-plugins-official>,
  `plugins/ralph-loop`.
- Install: `/plugin install ralph-loop@claude-plugins-official`.
- License: MIT.
- What it does / why it matters: iterative self-referential loop — a
  `Stop` hook re-feeds the prompt until a completion promise is met.
  Slash form:
  `/ralph-loop "prompt" --max-iterations 10 --completion-promise "DONE"`.
  Related built-ins `/loop`, `/goal`, `/batch` now cover similar
  ground.
- Notes / caveats: **uses Stop hooks**; expect autonomous session
  extension. Call that out to users.

### `andrej-karpathy-skills` (community, high traction)

- Source:
  <https://github.com/multica-ai/andrej-karpathy-skills> (org mirror)
  and `forrestchang/andrej-karpathy-skills` (author). ~194K stars
  combined; created 2026-01-27, grew substantially through this
  window.
- Install: `/plugin marketplace add forrestchang/andrej-karpathy-skills`
  then `/plugin install andrej-karpathy-skills@karpathy-skills`. Or drop
  the raw `CLAUDE.md` into a project.
- License: MIT.
- What it does / why it matters: a single `CLAUDE.md` encoding four
  behavioral rules (Think Before Coding, Simplicity First, Surgical
  Changes, Goal-Driven Execution) derived from Karpathy's viral
  observations on LLM coding failure modes.
- Notes / caveats: **Modifies `CLAUDE.md`.** No hooks, no shell —
  behavioral prompting only. Third-party marketplace, not
  Anthropic-managed. Read the file before adopting; it materially
  changes Claude's default behavior.

### `caveman` (community)

- Source: `juliusbrussee/caveman`
  ([listing](https://claudemarketplaces.com/skills/juliusbrussee/caveman/caveman)).
- Install: third-party marketplace add, or `npx skills add` pattern.
- License: MIT (per listing).
- What it does / why it matters: strips narration / pleasantries from
  responses while keeping code, commands, and error strings byte-exact.
  Reported ~65% output-token reduction on long agentic runs. Ships
  intensity modes (`lite` / `full` / `ultra` / `wenyan`) plus a
  `compress` sub-skill that rewrites `CLAUDE.md` for ~46% input-token
  savings.
- Notes / caveats: the `compress` sub-skill **rewrites `CLAUDE.md`** —
  flag before enabling. Third-party.

## Skills (loading semantics changes)

The distinction between "plugin" and "skill" narrowed considerably
this window. Key shifts:

- **v2.1.157 (2026-05-29) — auto-load from `.claude/skills/`.** Any
  folder with a `.claude-plugin/plugin.json` (or a top-level
  `SKILL.md`) under `.claude/skills/` loads as `<name>@skills-dir` on
  next session start — no marketplace, no `--plugin-dir`.
- **`claude plugin init <name>`** scaffolds a plugin under
  `~/.claude/skills/<name>/` with a starter `SKILL.md`,
  `.claude-plugin/plugin.json`, and optional `--with skills hooks`
  folders. Auto-loads as `<name>@skills-dir` next session.
- **v2.1.178 (2026-06-15) — nested `.claude/skills/`** are loaded when
  working on files under that subtree; on a name clash the nested
  skill appears as `<dir>:<name>` so both stay available.
- **v2.1.169 (2026-06-08) — `disableBundledSkills`** setting (and
  `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` env var) hide bundled skills,
  workflows, and built-in slash commands from the model. Also: skill
  hot-reload now re-announces only changed skills.
- **v2.1.181 (2026-06-17) — nested skills with directory-qualified
  names** no longer blocked by permission prompts in non-interactive
  runs; skill-listing truncation warning now reports how many
  descriptions are affected.
- **v2.1.186 (2026-06-22) — Skills section added to `/plugin`
  Installed tab.**
- **v2.1.193 (2026-06-25)** and later: assorted MCP retry /
  reliability improvements benefit any skill that calls MCP tools.

## Open questions / follow-ups

- **Anthropic-managed vs. partner labeling on the marketplace.**
  `marketplace.json` mixes first-party (`./plugins/...`),
  Anthropic-vendored external plugins (`./external_plugins/...`), and
  pointer entries to third-party repos. There is no in-CLI trust label
  yet; enterprise users have `blockedMarketplaces` but no
  `trustedPublishers` primitive. Worth watching.
- **Star counts on the Karpathy skill vary by mirror** (194K on the
  org mirror per WebFetch; other sources cite 132K / 144K / 220K
  combined). Verify at time of quoting.
- **`receipts` plugin** listed in `anthropics/claude-plugins-official/plugins/`
  by directory listing, but no independent documentation was found for
  what it does. Skipped a full writeup rather than guess.
- **`disableSkillShellExecution` interaction with `.claude/skills/`
  auto-load** — the setting predates auto-load. Worth confirming
  whether the policy still hits inline shells inside auto-loaded
  plugins that live under skills directories (expected: yes, since
  they load as `<name>@skills-dir` plugins).
- **License coverage on community skills is inconsistent** —
  `karpathy-skills` and `caveman` list MIT; `valyu` was not verified.
  Any recommendation should re-check licenses at install time.
- **`karpathy-skills` writes to `CLAUDE.md`** and `caveman`'s
  `compress` sub-skill **rewrites `CLAUDE.md`** — surface both as
  caveats when recommending either.
